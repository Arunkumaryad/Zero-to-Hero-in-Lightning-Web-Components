# Books Listing App — Salesforce LWC + Google Books API

A Salesforce Lightning Web Component (LWC) that searches for books using the **Google Books API** and displays the results in a responsive card-style layout.

This README is based on the three supplied screenshots. It explains the code in simple language, preserves the definitions and implementation approach shown in the screenshots, and adds practical setup notes and interview questions.

---

## 1. Project Overview

**Project / folder name:** `Books Listing App`  
**LWC component name shown in the screenshots:** `bookApp`  
**External API:** Google Books API  
**Endpoint:** `https://www.googleapis.com/books/v1/volumes`

### What the application does

- Shows a search input where a user can search by book name or author.
- Calls the Google Books API when the component loads and when the user types a search.
- Waits for one second after typing before making the search request (debouncing).
- Requests up to 20 results.
- Shows a loading spinner while the request is running.
- Shows an error message if the request fails.
- Shows a “No books found!” message if the API returns no book items.
- Displays a book thumbnail, title, authors, published date, and average rating.
- Ignores older API responses if a newer search has already been started.

> **Note about the initial load:** The screenshot's `connectedCallback()` calls `fetchBookData()`, but `query` initially equals an empty string. The method then exits because the query is empty. Therefore, the component does not make an actual API request until a non-empty search is entered.

## 2. Google Books API — Definition

**Definition:** The Google Books API is a REST API that allows applications to search for and retrieve information about books from Google's book catalogue. It can return information such as a book's title, authors, publication date, thumbnail image, and average rating.

The screenshot uses this endpoint:

```text
https://www.googleapis.com/books/v1/volumes
```

A search request is built like this:

```javascript
const url = `${BOOK_URL}?q=${encodeURIComponent(searchQuery)}&maxResults=20`;
```

For example, a search for `Salesforce` is sent as a URL with the `q` search parameter and `maxResults=20`.

### Important URL parameters

| Parameter | Meaning |
|---|---|
| `q` | Search query. It can contain a book title, author, or other supported search terms. |
| `maxResults` | Maximum number of results requested. The screenshot uses `20`. |

`encodeURIComponent()` safely encodes the user's search text so spaces and special characters can be included in a URL query parameter.

Official API documentation: [Google Books API — Volumes](https://developers.google.com/books/docs/v1/reference/volumes)

## 4. JavaScript Controller

**File:** `bookApp.js`

The following code reproduces the implementation visible across the second and third screenshots, with consistent indentation:

```javascript
import { LightningElement } from 'lwc';

const BOOK_URL = 'https://www.googleapis.com/books/v1/volumes';

export default class BookApp extends LightningElement {
    query = '';
    books = [];
    isLoading = false;
    errorMessage = '';
    timer;

    requestId = 0;

    connectedCallback() {
        this.fetchBookData();
    }

    disconnectedCallback() {
        clearTimeout(this.timer);
        this.requestId++;
    }

    async fetchBookData() {
        const currentRequest = ++this.requestId;

        const searchQuery = this.query.trim();

        if (!searchQuery) {
            this.books = [];
            this.errorMessage = '';
            this.isLoading = false;
            return;
        }

        this.isLoading = true;
        this.errorMessage = '';
        this.books = [];

        try {
            const url = `${BOOK_URL}?q=${encodeURIComponent(searchQuery)}&maxResults=20`;

            const response = await fetch(url);

            if (!response.ok) {
                if (response.status === 429) {
                    throw new Error(
                        'Too many requests. Please try again after some time.'
                    );
                }

                if (response.status === 403) {
                    throw new Error('Access denied by Google Books API.');
                }

                throw new Error(
                    `Something went wrong: ${response.status}`
                );
            }

            const data = await response.json();

            // Ignore outdated search responses
            if (currentRequest !== this.requestId) {
                return;
            }

            this.books = data.items
                ? this.formatData(data.items)
                : [];

            if (this.books.length === 0) {
                this.errorMessage = 'No books found!';
            }

        } catch (error) {
            if (currentRequest !== this.requestId) {
                return;
            }

            this.books = [];
            this.errorMessage = error.message;

            console.error('Google Books API Error:', error);

        } finally {
            if (currentRequest === this.requestId) {
                this.isLoading = false;
            }
        }
    }

    fetchBooksHandler(event) {
        this.query = event.target.value;

        clearTimeout(this.timer);

        this.timer = setTimeout(() => {
            this.fetchBookData();
        }, 1000);
    }

    formatData(items) {
        return items.map(item => {
            const volumeInfo = item.volumeInfo || [];
            const imageLinks = volumeInfo.imageLinks || [];

            return {
                id: item.id,

                thumbnail:
                    imageLinks.thumbnail ||
                    imageLinks.smallThumbnail ||
                    null,

                title:
                    volumeInfo.title ||
                    'Title Not Available',

                authors: volumeInfo.authors
                    ? volumeInfo.authors.join(', ')
                    : 'Unknown Author',

                publishedDate:
                    volumeInfo.publishedDate ||
                    'Not Available',

                averageRating:
                    volumeInfo.averageRating ?? 'NA'
            };
        });
    }

    get hasBooks() {
        return this.books.length > 0;
    }
}
```

> The screenshot shows `volumeInfo || []` and `imageLinks || []`. They are retained above to reflect the screenshot's implementation. In JavaScript, these values are objects when present; using `{}` as the fallback is generally clearer. The `||` operator still allows property access to fall back safely when the original value is missing.

## 5. JavaScript Code Explanation

### 5.1 Import LightningElement

```javascript
import { LightningElement } from 'lwc';
```

`LightningElement` is the base class used to create a Lightning Web Component. The `BookApp` class extends it to use LWC functionality.

### 5.2 Google Books API URL

```javascript
const BOOK_URL = 'https://www.googleapis.com/books/v1/volumes';
```

Stores the base URL of the Google Books API. The search query and result limit are added to this URL when the request is created.

### 5.3 Component properties

```javascript
query = '';
books = [];
isLoading = false;
errorMessage = '';
timer;

requestId = 0;
```

| Property | Purpose |
|---|---|
| `query` | Stores the text entered in the search box. |
| `books` | Stores the formatted book records returned by the API. |
| `isLoading` | Controls whether the loading spinner is displayed. |
| `errorMessage` | Stores an error or no-results message. |
| `timer` | Stores the timeout ID used for debouncing. |
| `requestId` | Tracks the latest request so older responses can be ignored. |

### 5.4 `connectedCallback()`

```javascript
connectedCallback() {
    this.fetchBookData();
}
```

**Definition:** `connectedCallback()` is a lifecycle hook that is called when a component is inserted into the DOM.

In this project, it calls `fetchBookData()` when the component is connected.

Because `query` starts as an empty string, `fetchBookData()` immediately returns without making an API request. A request is made after the user enters a non-empty search term.

### 5.5 `disconnectedCallback()`

```javascript
disconnectedCallback() {
    clearTimeout(this.timer);
    this.requestId++;
}
```

**Definition:** `disconnectedCallback()` is a lifecycle hook that is called when a component is removed from the DOM.

In this project:

- `clearTimeout(this.timer)` cancels a pending search timer.
- `this.requestId++` invalidates any request that is still in progress. When its response arrives, the request ID check prevents the old result from being applied.

### 5.6 `async fetchBookData()`

```javascript
async fetchBookData() {
    const currentRequest = ++this.requestId;
    const searchQuery = this.query.trim();
}
```

This asynchronous method performs the API search.

- `async` allows the method to use `await`.
- `++this.requestId` increments the request counter and stores the ID of this request.
- `trim()` removes whitespace from the beginning and end of the search text.

### 5.7 Empty search validation

```javascript
if (!searchQuery) {
    this.books = [];
    this.errorMessage = '';
    this.isLoading = false;
    return;
}
```

If the search input is empty, the method clears the displayed books and error, stops the loading state, and exits without calling the API.

### 5.8 Loading state

```javascript
this.isLoading = true;
this.errorMessage = '';
this.books = [];
```

Before sending a request:

- Shows the loading spinner.
- Clears any previous error.
- Clears the previous search results.

### 5.9 Create the API URL

```javascript
const url =
    `${BOOK_URL}?q=${encodeURIComponent(searchQuery)}&maxResults=20`;
```

Builds the request URL.

- `BOOK_URL` is the API endpoint.
- `q` is the search query.
- `encodeURIComponent()` encodes the search text.
- `maxResults=20` requests up to 20 results.

### 5.10 Call the API using `fetch()`

```javascript
const response = await fetch(url);
```

**Definition:** `fetch()` is a JavaScript Web API used to make HTTP requests and return a Promise that resolves to a Response object.

`await` pauses the asynchronous function until the response is available.

### 5.11 Check the response status

```javascript
if (!response.ok) {
    if (response.status === 429) {
        throw new Error(
            'Too many requests. Please try again after some time.'
        );
    }

    if (response.status === 403) {
        throw new Error('Access denied by Google Books API.');
    }

    throw new Error(
        `Something went wrong: ${response.status}`
    );
}
```

- `response.ok` is true for successful HTTP status codes (200–299).
- `429` means too many requests / rate limiting.
- `403` means the server refused the request.
- Other unsuccessful statuses produce a general error.

`throw new Error()` sends execution to the `catch` block.

### 5.12 Convert the response into JSON

```javascript
const data = await response.json();
```

Reads the response body and parses it as JSON.

The Google Books API returns a response containing an `items` array when results are available.

### 5.13 Ignore outdated search responses

```javascript
if (currentRequest !== this.requestId) {
    return;
}
```

This is an important part of the implementation.

Imagine the user searches for `Java` and quickly changes the search to `Salesforce`.

- The first request may take longer.
- The second request may finish first.
- Without protection, the older response could overwrite the newer search results.

The request ID check ensures that only the latest request can update the component's state.

### 5.14 Store and format the books

```javascript
this.books = data.items
    ? this.formatData(data.items)
    : [];
```

- If the API response contains `items`, it sends them to `formatData()`.
- If there are no items, it stores an empty array.

```javascript
if (this.books.length === 0) {
    this.errorMessage = 'No books found!';
}
```

Displays the no-results message when the formatted list is empty.

### 5.15 Error handling

```javascript
catch (error) {
    if (currentRequest !== this.requestId) {
        return;
    }

    this.books = [];
    this.errorMessage = error.message;

    console.error('Google Books API Error:', error);
}
```

If the API request or JSON parsing fails:

- Checks whether the request is still the latest request.
- Clears the books array.
- Stores the error message.
- Logs the error in the browser console.

### 5.16 `finally` block

```javascript
finally {
    if (currentRequest === this.requestId) {
        this.isLoading = false;
    }
}
```

**Definition:** A `finally` block executes after the `try` block completes, whether it succeeds or fails.

Here, it hides the loading spinner only when the request is still the latest request. This prevents an older request from changing the loading state of a newer search.

### 5.17 Search handler and debounce

```javascript
fetchBooksHandler(event) {
    this.query = event.target.value;

    clearTimeout(this.timer);

    this.timer = setTimeout(() => {
        this.fetchBookData();
    }, 1000);
}
```

This method handles changes in the search input.

- `event.target.value` gets the entered search text.
- `clearTimeout()` cancels the previous pending timer.
- `setTimeout()` waits for 1000 milliseconds (1 second).
- After the delay, `fetchBookData()` is called.

**Definition of Debouncing:** Debouncing is a technique that delays the execution of a function until a specified period has passed without another triggering event.

In this project, debouncing prevents an API call from being made for every keystroke. The API request is made after the user stops typing for one second.

### 5.18 `formatData(items)`

```javascript
formatData(items) {
    return items.map(item => {
        const volumeInfo = item.volumeInfo || [];
        const imageLinks = volumeInfo.imageLinks || [];

        return {
            id: item.id,

            thumbnail:
                imageLinks.thumbnail ||
                imageLinks.smallThumbnail ||
                null,

            title:
                volumeInfo.title ||
                'Title Not Available',

            authors: volumeInfo.authors
                ? volumeInfo.authors.join(', ')
                : 'Unknown Author',

            publishedDate:
                volumeInfo.publishedDate ||
                'Not Available',

            averageRating:
                volumeInfo.averageRating ?? 'NA'
        };
    });
}
```

The Google Books API response contains nested data. `formatData()` converts that response into a simpler structure that is convenient for the HTML template.

| Property | Source / fallback |
|---|---|
| `id` | `item.id` |
| `thumbnail` | `imageLinks.thumbnail`, then `imageLinks.smallThumbnail`, then `null` |
| `title` | `volumeInfo.title`, otherwise `Title Not Available` |
| `authors` | Authors joined with commas, otherwise `Unknown Author` |
| `publishedDate` | `volumeInfo.publishedDate`, otherwise `Not Available` |
| `averageRating` | `volumeInfo.averageRating`, otherwise `NA` |

**Why use `map()`?**  
`map()` creates a new array by transforming each item in the original array.

**Why use `join(', ')?**  
The API can return multiple authors as an array. `join(', ')` converts the array into a readable comma-separated string.

**Why use `??` for the average rating?**  
The nullish coalescing operator `??` uses the fallback only when the left-hand value is `null` or `undefined`. It does not replace valid values such as `0`.

### 5.19 Getter — `hasBooks`

```javascript
get hasBooks() {
    return this.books.length > 0;
}
```

**Definition:** A getter is a method that is accessed like a property.

Here, `hasBooks` returns `true` when the books array contains at least one item. The HTML uses it to decide whether to display the book listing.

## 9. Important JavaScript and LWC Concepts

### 9.1 Lifecycle Hooks

Lifecycle hooks are special methods that run at specific stages of an LWC's lifecycle.

- `connectedCallback()` — called when the component is inserted into the DOM.
- `disconnectedCallback()` — called when the component is removed from the DOM.

### 9.2 Asynchronous JavaScript

Asynchronous operations allow JavaScript to perform tasks such as API requests without blocking the main execution thread.

This project uses:

- `async`
- `await`
- `fetch()`
- `Promise`
- `try/catch/finally`

### 9.3 REST API

A REST API allows applications to communicate over HTTP using URLs and methods such as GET and POST.

This project uses an HTTP GET request to retrieve book information.

### 9.4 `fetch()`

`fetch()` is a browser-provided JavaScript function used to make HTTP requests. It returns a Promise that resolves to a Response object.

### 9.5 JSON

JSON (JavaScript Object Notation) is a lightweight data format used to exchange information between applications.

The Google Books API returns JSON data, which is converted into JavaScript objects using:

```javascript
const data = await response.json();
```

### 9.6 Debouncing

Debouncing delays function execution until a period of inactivity has passed.

In this project, the delay is 1000 milliseconds, which reduces unnecessary API requests while a user types.

### 9.7 `setTimeout()` and `clearTimeout()`

- `setTimeout()` schedules a function to run after a specified delay.
- `clearTimeout()` cancels a previously scheduled timeout.

### 9.8 `map()`

`map()` transforms every item in an array and returns a new array.

### 9.9 Optional Fallback Values

The project uses operators to provide fallback values:

- `||` — returns the right-hand value when the left-hand value is falsy.
- `??` — returns the right-hand value only when the left-hand value is `null` or `undefined`.

### 9.10 Getter

A getter allows a method to be accessed like a property. The `hasBooks` getter returns whether the books array contains any records.

### 9.11 Conditional Rendering

LWC uses directives such as:

```html
<template if:true={isLoading}>
```

and:

```html
<template if:false={book.thumbnail}>
```

These directives display content conditionally based on JavaScript property values.

### 9.12 Iteration

The directive:

```html
<template for:each={books} for:item="book">
```

iterates over the books array and renders one item for each book.

### 9.13 Responsive Layout

`lightning-layout` and `lightning-layout-item` provide a responsive grid layout.

In this project:

- Small devices: one card per row.
- Medium devices: two cards per row.
- Large devices: four cards per row.

## 10. Interview Questions and Answers

### Basic Questions

**Q1. What is an API?**  
An API (Application Programming Interface) allows two software applications to communicate and exchange data.

**Q2. What is a REST API?**

## 12. Common Mistakes and Solutions

| Problem | Possible reason | Solution |
|---|---|---|
| API request blocked | CSP restriction | Add the API host to CSP Trusted URLs with the required directive. |
| CORS error | API does not allow the browser origin | Verify the external API's CORS support. CSP configuration alone cannot fix CORS. |
| No results displayed | Empty or unmatched search query | Enter a valid search term and check the API response. |
| Spinner never disappears | Loading state not reset | Verify the `finally` block and latest request ID. |
| Old results overwrite new results | Multiple requests finish in a different order | Use request ID checks or request cancellation. |
| Too many API calls | Request sent on every keystroke | Use debouncing. |
| Missing book cover | API response has no image link | Display the `No Cover Available` fallback. |
| Missing author | API response does not include authors | Display `Unknown Author`. |
| Missing rating | API response has no average rating | Display `NA`. |
| Search does not run | Search query is empty | Enter a non-empty search term. |

## 13. Optional Improvements for a Production Version

The following are improvements, not additional features shown in the supplied screenshots.

1. **Use object fallbacks:** Replace `volumeInfo || []` and `imageLinks || []` with `volumeInfo || {}` and `imageLinks || {}` for clearer object handling.
2. **Improve accessibility:** Add meaningful alt text and ensure error messages are announced to screen readers.
3. **Improve error display:** Distinguish network errors, API errors, and empty search results.
4. **Add a retry button:** Allow the user to retry a failed search.
5. **Add pagination:** Support additional result pages using the Google Books API's `startIndex` parameter.
6. **Cancel outdated requests:** Use `AbortController` where appropriate to stop unnecessary network work, in addition to protecting UI state with request IDs.
7. **Add tests:** Test empty searches, successful responses, no results, failed requests, and stale response handling.
8. **Improve image handling:** Add consistent image dimensions and a styled placeholder for missing covers.

### Small code-quality refinement

The screenshot uses:

```javascript
const volumeInfo = item.volumeInfo || [];
const imageLinks = volumeInfo.imageLinks || [];
```

A clearer object fallback is:

```javascript
const volumeInfo = item.volumeInfo || {};
```

This is a recommended refinement because both values are expected to be objects.
