# App Creation and Component Deployment (LWC)

This document explains the complete process of **creating a custom Lightning App**, **creating a Lightning Page**, **deploying a custom LWC component onto that page**, and finally **assigning the component/app** so it becomes visible and usable in Salesforce.

---

## 📌 Overview: The 4-Step Process

Before building anything, it's important to understand the overall flow. Every custom component you build ultimately needs a "home" inside Salesforce — that home is created through this 4-step process:

```
App Creation
     │
     ▼
Page Creation
     │
     ▼
Component Deployment
     │
     ▼
Component Assignment
```

| Step | What It Means |
|---|---|
| **1. App Creation** | Creating a new Lightning App (a container that groups tabs, pages, and functionality together for users). |
| **2. Page Creation** | Creating a new Lightning Page (App Page / Record Page / Home Page) inside the Lightning App Builder — this page is where your components will actually live. |
| **3. Component Deployment** | Dragging and dropping your custom Lightning Web Component onto the Lightning Page you created, and activating that page. |
| **4. Component Assignment** | Assigning the activated page to the app, and setting visibility for Lightning Experience and Mobile Navigation so users can actually see and access it. |

Each of these steps is explained in detail below with screenshots.

---

## 1️⃣ App Creation — Lightning Experience App Manager

To begin, we first need a **Lightning App** where our custom page/component will eventually live.

### Steps:
1. Go to **Setup** (gear icon, top right).
2. In the **Search Setup** box, type `App`.
3. Click on **App Manager** under the **Apps** section (left sidebar).
4. On the **Lightning Experience App Manager** page, click the **New Lightning App** button (top right).
5. Follow the setup wizard to give your app a name, branding, and select the navigation items.

> 🔎 **Definition:** The **Lightning Experience App Manager** lets you create, edit, and manage apps that group together tabs, objects, and Lightning pages so users can access related functionality from one place.

**Screenshot Reference:** Setup → Search "App" → App Manager → New Lightning App / New External Client App buttons highlighted.

---

## 2️⃣ Page Creation — Lightning App Builder

Once the app container exists, the next step is to create the **Lightning Page** that will actually hold your custom component.

### Steps:
1. Go to **Setup** → Search for `App Builder`.
2. Click on **Lightning App Builder** under **User Interface**.
3. You'll see a list of existing **Lightning Pages** (with columns like Label, Name, Type, Created By, Last Modified By).
4. Click the **New** button to create a new Lightning Page.
5. Choose the page type:
   - **App Page** – a standalone page shown as an app tab.
   - **Record Page** – shown on a specific object's record detail.
   - **Home Page** – shown on the Home tab.
6. Give the page a name and proceed to the builder canvas.

> 🔎 **Definition:** The **Lightning App Builder** provides an easy-to-use graphical (drag-and-drop) interface for creating custom Lightning pages for Salesforce Lightning Experience and the mobile app. Lightning pages are built using **Lightning components** — compact, configurable, and reusable elements that you can drag and drop into regions of the page.

**Screenshot Reference:** Setup → Search "App Builder" → Lightning App Builder → list of Lightning Pages → New button highlighted.

---

## 3️⃣ Component Deployment — Adding Your LWC to the Page

Now that the page exists, this is where your **custom Lightning Web Component** actually gets placed onto the canvas.

### Steps:
1. Inside the **Lightning App Builder** canvas, locate your custom component in the **Components** panel on the left (under the "Custom" section).
2. **Drag and drop** your component onto the page layout region where you want it to appear.
3. Configure any exposed component properties (if your component has `@api` properties, you can set their values here directly in the builder).
4. Click **Save**.
5. After saving, click **Activation** to configure how/where this page should be shown.

### Activation — Page Settings
A popup titled **"Activation: [Your Page Name]"** appears with three tabs:
- **Page Settings** – Set the page **Name** and choose an **Icon** to represent your app in Lightning Experience and the mobile app.
- **Lightning Experience** – Choose which apps this page should be assigned to.
- **Mobile Navigation** – Configure visibility on the mobile app's navigation menu.

**Screenshot Reference:** Activation popup → Page Settings tab → Name field ("LWC Fundamentals") + Icon selection ("Change...") → Cancel / Save buttons.

> 🔎 **Definition:** **Page Activation** is the process of making a created Lightning Page live/usable. When you activate a page, a custom tab is created for it, and you can manage that tab's visibility later from Setup.

---

## 4️⃣ Component Assignment — Assigning the Page to an App

The final step is to tell Salesforce **which app** this newly activated page should belong to, so that end users can actually navigate to it.

### Steps:
1. In the **Activation** popup, go to the **Lightning Experience** tab.
2. From the list of available apps on the left (e.g., Sales Console, Salesforce CMS, Shield, Subscription Management, etc.), **select the app** you want this page assigned to (e.g., *"Zero to Hero in LWC"*).
3. On the right panel, click **Add page to app**.
4. Once added, you can **drag the page** to the exact position you want it to appear within that app's navigation.
5. Click **Save** to finalize the assignment.

> 🔎 **Definition:** **Component/Page Assignment** links your activated Lightning Page to a specific Lightning App, making the page (and the component deployed on it) accessible to users through that app's navigation.

**Screenshot Reference:** Activation popup → Lightning Experience tab → App list (left) → "Zero to Hero in LWC" selected → "Add page to app" button (right) → Save button.

## 📊 Summary Table

| Step | Where To Go (Setup Path) | Purpose |
|---|---|---|
| App Creation | Setup → App Manager → New Lightning App | Create the app container |
| Page Creation | Setup → App Builder → New | Create a page to hold components |

| Component Assignment | Activation popup → Lightning Experience tab → Add page to app | Link the page to the app so users can access it |

---

## ✅ Quick Recap

1. **Create an App** using the App Manager (`New Lightning App`).
2. **Create a Page** using the Lightning App Builder (`New` Lightning Page).
3. **Deploy your Component** by dragging it onto the page canvas, then **Save** and **Activate** the page (set Name + Icon).
4. **Assign the Page** to your app under the *Lightning Experience* tab (`Add page to app`) and **Save**.

Once all 4 steps are done, your custom Lightning Web Component becomes fully accessible to users inside the assigned Salesforce app — both on desktop (Lightning Experience) and on the mobile app (if Mobile Navigation is configured).
