# Improved Conditional Rendering in LWC

This document explains the **new, improved conditional rendering directives** introduced by Salesforce, which extend upon the older `if:true` / `if:false` directives covered in the previous topic.

---

## 📌 What is Improved Conditional Rendering?

> 🔎 **Definition (from training material):**
> In **Spring '23**, Salesforce has announced the new improved Conditional Directives: **`lwc:if`**, **`lwc:elseif`**, and **`lwc:else`**.

These three new directives were introduced as a more powerful and more readable replacement for the older `if:true` / `if:false` directives — because unlike the old ones, these new directives support **`if / else-if / else`** style branching, similar to conditional logic in standard programming languages.

---

## ⚠️ Important Note on Old Directives (`if:true` / `if:false`)

> 🔎 **Definition (from training material):**
> **Old directives will not go away anywhere soon**, but **in future they will be deprecated by Salesforce**.

This means:
- Your existing code using `if:true` and `if:false` will **continue to work** for now — there's **no immediate need to rewrite everything**.
- However, since Salesforce has signaled that these older directives **will eventually be deprecated**, it is **recommended to use the new `lwc:if`, `lwc:elseif`, and `lwc:else` directives** for any **new development** going forward.

## 🧩 The Three New Directives

| Directive | Purpose |
|---|---|
| **`lwc:if`** | Renders the block when the expression is **true** (equivalent to starting an `if` condition) |
| **`lwc:elseif`** | Renders the block when the **previous condition(s) were false** AND this expression is **true** (equivalent to `else if`) |
| **`lwc:else`** | Renders the block when **none of the above conditions** were true (equivalent to a final `else`) |

### General Syntax (based on official Salesforce pattern)

```html
<template>
    <template lwc:if={expression1}>
        Content shown when expression1 is true
    </template>
    <template lwc:elseif={expression2}>
        Content shown when expression1 is false and expression2 is true
    </template>
    <template lwc:else>
        Content shown when none of the above expressions are true
    </template>
</template>
```

**Key differences from the old directives:**
- `lwc:if` / `lwc:elseif` / `lwc:else` are used **together as a single conditional chain** on **sibling `<template>` tags**, similar to writing `if / else if / else` in JavaScript.
- The old `if:true` / `if:false` directives had to be written as **two completely separate, independent blocks** — there was no built-in way to chain multiple conditions together. The new directives solve this by allowing **multiple branches** in one logical group.

## ✅ Quick Recap

- Salesforce introduced `lwc:if`, `lwc:elseif`, and `lwc:else` in the **Spring '23** release as an **improved** way to do conditional rendering.
- The **old directives (`if:true` / `if:false`) are not going away immediately**, but they **will be deprecated in the future**, so new development should prefer the new directives.
- Unlike the old directives, the new ones support proper **if / else-if / else chaining** using sibling `<template>` tags.
- For the most accurate and up-to-date syntax details, refer to the **official Salesforce release notes link** shared above, and watch the **New Improved Conditional Directive video** under the **Spring '23 release section**, as recommended in the training material.
