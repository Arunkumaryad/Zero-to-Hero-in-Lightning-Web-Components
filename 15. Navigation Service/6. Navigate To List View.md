# Navigate To List View 

## 1. Overview

This project demonstrates how to use the Salesforce Lightning Web Component (LWC) Navigation Service to open the **Recent Contacts** list view when a user clicks a button.

The component uses:
- `NavigationMixin` from `lightning/navigation`
- A PageReference with `type: 'standard__objectPage'`
- `actionName: 'list'` to open an object's list page
- `state.filterName: 'Recent'` to request the Recent list view

## 2. Definitions and Syntax from the Screenshots

### Navigation Service

The Navigation Service allows an LWC to navigate to supported Salesforce pages. In the component's JavaScript file, import `NavigationMixin` from `lightning/navigation` and apply it to the component's base class.

```javascript
import { NavigationMixin } from 'lightning/navigation';

export default class MyCustomElement extends NavigationMixin(LightningElement) {}
```

To dispatch a navigation request, call:

```javascript
this[NavigationMixin.Navigate](pageReference, [replace]);
```

- **`pageReference`**: An object that describes the page to navigate to.
- **`replace`**: An optional Boolean. It defaults to `false`. If `true`, the current browser-history entry is replaced.

### PageReference

A PageReference is an object that describes a page in Salesforce Lightning Experience, Experience Builder sites, or the Salesforce mobile app. It specifies the destination using properties such as `type`, `attributes`, and optional `state`.

The screenshot uses the following PageReference:

```javascript
{
    type: 'standard__objectPage',
    attributes: {
        objectApiName: 'Contact',
        actionName: 'list'
    },
    state: {
        filterName: 'Recent'
    }
}
```

### Meaning of the PageReference properties

- **`type: 'standard__objectPage'`** — navigates to a standard object page.
- **`objectApiName: 'Contact'`** — identifies the Contact object.
- **`actionName: 'list'`** — opens the object's list page.
- **`state.filterName: 'Recent'`** — requests the Recent list view.

The exact list-view behavior can depend on the object and the Salesforce UI context. If you want a specific custom list view, use its supported list-view identifier rather than assuming every list view is named `Recent`.

## 5. JavaScript — `navigateToObjectPage.js`

This is the JavaScript logic shown in the screenshot, formatted for readability:

```javascript
import { LightningElement } from 'lwc';
import { NavigationMixin } from 'lightning/navigation';
import { encodeDefaultFieldValues } from 'lightning/pageReferenceUtils';

export default class NavigateToObjectPage extends NavigationMixin(LightningElement) {
    navigateToListView() {
        this[NavigationMixin.Navigate]({
            type: 'standard__objectPage',
            attributes: {
                objectApiName: 'Contact',
                actionName: 'list'
            },
            state: {
                filterName: 'Recent'
            }
        });
    }
}
```

**Note:** `encodeDefaultFieldValues` appears in the screenshot's imports but is not used in the list-view method. It is not required for this example, so a cleaner version removes that unused import. Use this recommended JavaScript instead:

```javascript
import { LightningElement } from 'lwc';
import { NavigationMixin } from 'lightning/navigation';

export default class NavigateToObjectPage extends NavigationMixin(LightningElement) {
    navigateToListView() {
        this[NavigationMixin.Navigate]({
            type: 'standard__objectPage',
            attributes: {
                objectApiName: 'Contact',
                actionName: 'list'
            },
            state: {
                filterName: 'Recent'
            }
        });
    }
}
```

### JavaScript explanation

1. `LightningElement` is the base class for an LWC.
2. `NavigationMixin` adds navigation functionality to the component.
3. `navigateToListView()` is the event handler for the button.
4. `NavigationMixin.Navigate` sends the navigation request to Salesforce.
5. `standard__objectPage` specifies a standard object page.
6. `objectApiName: 'Contact'` identifies the object.
7. `actionName: 'list'` requests the list page.
8. `filterName: 'Recent'` requests the Recent list view.

## 6. Metadata — `navigateToObjectPage.js-meta.xml`

The screenshot uses API version `67.0` and exposes the component on a Lightning App Page:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<LightningComponentBundle xmlns="http://soap.sforce.com/2006/04/metadata">
    <apiVersion>67.0</apiVersion>
    <isExposed>true</isExposed>
    <targets>
        <target>lightning__AppPage</target>
    </targets>
</LightningComponentBundle>
```

Use an API version supported by your Salesforce org. The `lightning__AppPage` target makes the component available in Lightning App Builder for Lightning App Pages.

## 7. Create, Deploy, and Test

1. Open your Salesforce DX project in VS Code.
2. Go to `force-app/main/default/lwc/`.
3. Create an LWC named `navigateToObjectPage`.
4. Add the HTML, JavaScript, and metadata files shown above.
5. Save the files.
6. Deploy the component from VS Code, or use:

   ```bash
   sf project deploy start --source-dir force-app/main/default/lwc/navigateToObjectPage
   ```

7. In Salesforce, open **Setup → Lightning App Builder**.
8. Create or edit a Lightning App Page.
9. Drag the component onto the page.
10. Save and activate the page if necessary.
11. Open the app page and click **Navigate To List View**.
12. Confirm that Salesforce navigates to the Contact list page and attempts to show the Recent list view.

## 8. Troubleshooting

- **Component does not appear in App Builder:** Check `<isExposed>true</isExposed>`, the `lightning__AppPage` target, and deployment status.
- **Button does nothing:** Confirm that `onclick={navigateToListView}` matches the JavaScript method name exactly.
- **Wrong object list appears:** Confirm that `objectApiName` is set to `'Contact'`.
- **The Recent list view is not selected:** Check the `filterName` value and the list-view support for the target object/context.
- **Deployment fails:** Check file names, XML syntax, API version, and the CLI deployment output.
- **User cannot access Contacts:** Check object permissions and access to the relevant list views.

## 9. Interview Topics

A Salesforce LWC service used to navigate to supported Salesforce pages without hardcoding URLs.

### PageReference
An object that describes a destination page. Common properties include `type`, `attributes`, and `state`.

## 10. Interview Questions and Answers

**Q1. What is the Navigation Service in LWC?**  
It allows LWC components to navigate to supported Salesforce pages and destinations.

**Q2. What is `NavigationMixin`?**  
It is a mixin from `lightning/navigation` that provides navigation methods to an LWC.

**Q3. What is a PageReference?**  
A structured object that describes the destination page and any supported navigation parameters.

**Q4. What does `standard__objectPage` mean?**  
It identifies a standard Salesforce object page.

**Q5. What does `actionName: 'list'` do?**  
It requests the list page for the specified object.

**Q6. What is `filterName: 'Recent'` used for?**  
It requests the Recent list view in the destination list page.

**Q7. Why use Navigation Service instead of a hardcoded URL?**  
PageReferences are the supported, context-aware way to navigate in Lightning and avoid relying on internal URL formats.

**Q8. What is the purpose of `lightning__AppPage` in the XML file?**  
It makes the component available to be placed on a Lightning App Page through Lightning App Builder.

**Q9. Is `encodeDefaultFieldValues` required in this example?**  
No. It is used to prepopulate fields when navigating to a new-record form. It is not needed for navigation to a list view.

**Q10. How can this component navigate to another object's list page?**  
Change `objectApiName` to the target object's API name and provide a supported filter identifier.

## 11. Scenario-Based Interview Questions

**Scenario 1: The component opens the wrong object's list page.**  
Check the `objectApiName` value and make sure it matches the desired object's API name.

**Scenario 2: The list page opens, but Recent is not selected.**  
Verify the `filterName` value and whether the target context supports that filter identifier.

**Scenario 3: The component is not visible in Lightning App Builder.**  
Check `isExposed`, the `lightning__AppPage` target, and whether deployment succeeded.

**Scenario 4: The developer uses a hardcoded Salesforce URL for navigation.**  
Recommend a PageReference and `NavigationMixin.Navigate` because they are the supported approach for Lightning navigation.
