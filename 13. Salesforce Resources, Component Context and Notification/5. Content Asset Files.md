# Content Asset Files in Salesforce LWC

## Overview

This guide explains how to use a **Salesforce Content Asset File** in a Lightning Web Component (LWC). The training screenshots create an Asset File in Salesforce Files, import it with the `@salesforce/contentAssetUrl` scoped module, and display a download link in an LWC.

The sample file in the screenshots is a PDF named **AFE700036_ASSEMBLY-T.pdf**.

## 1. Actual Definition from the Training Screenshot

> Import content asset files from the `@salesforce/contentAssetUrl` scoped module. Convert a Salesforce file into a content asset file to use the file in custom apps and Community templates.

### Syntax shown in the screenshot

```javascript
import myContentAsset from '@salesforce/contentAssetUrl/contentAssetReference';
```

### Meaning

- `myContentAsset`: A JavaScript variable that refers to the content asset.
- `@salesforce/contentAssetUrl`: The LWC scoped module used to reference a Salesforce content asset.
- `contentAssetReference`: The API name/reference of the content asset.

In simple terms, this module lets an LWC reference a file that has been created as a Salesforce content asset.

> **Important:** A Content Asset is not the same as a Static Resource. Content assets are managed through Salesforce Files and asset libraries, while Static Resources are uploaded through Setup.

---

## 2. What Is a Content Asset File?

A **Content Asset File** is a Salesforce file made available as a content asset so it can be referenced by supported custom applications and Experience Cloud/community templates.

Common examples include PDFs, product brochures, user guides, images, logos, and other published content. Exact availability depends on the Salesforce feature and page where the asset is used.

---

## 3. Open the Asset Library

The screenshots show Salesforce **Files** and the **Libraries** section.

1. Open the Salesforce **App Launcher**.
2. Search for and open **Files**.
3. Select **Libraries** in the left navigation.
4. Open the library named **Asset Library**.

If the library is not available, check your org's Files/Libraries setup and user permissions.

---

## 4. Upload or Add a File to the Library

The screenshots show these actions:

- **Upload Asset File**
- **Add Files**

Use **Upload Asset File** to create a content asset from a file. Use **Add Files** to add an existing file to the library where appropriate.

The asset-creation dialog shows:

```text
Asset File Name: AFE700036_ASSEMBLY_T_pdf
API Name:        AFE700036_ASSEMBLY_T_pdf
```

It also shows these file-sharing options:

- **Let guest users see this asset file on public and login pages**
- **Make asset file available to Salesforce org users**

The second option is selected in the screenshot. Choose sharing settings according to the intended audience and your organization's security requirements.

Click **Save** to create the asset.

### Asset File Name vs. API Name

- **Asset File Name** is the name displayed when working with the asset.
- **API Name** is the identifier used to reference the asset in code and Salesforce features.

The sample API name in the screenshot is:

```text
AFE700036_ASSEMBLY_T_pdf
```

## 5. Import the Content Asset into LWC

The JavaScript screenshot shows:

```javascript
import { LightningElement } from 'lwc';

import TYPESCRIPT_FILE
    from '@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf';

export default class ContentAssetFiles extends LightningElement {
    file = TYPESCRIPT_FILE;
}
```

### Explanation

```javascript
import { LightningElement } from 'lwc';
```

Imports the base class used to create an LWC.

```javascript
import TYPESCRIPT_FILE
    from '@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf';
```

Imports a reference to the content asset whose API name is `AFE700036_ASSEMBLY_T_pdf`.

```javascript
file = TYPESCRIPT_FILE;
```

Stores the imported asset URL in a component property named `file`.

> The variable name `TYPESCRIPT_FILE` is just the name used in the screenshot. Since the asset is a PDF, a clearer name in a new implementation would be `ASSEMBLY_PDF` or `assemblyPdf`.

---

## 6. Display a Download Link in the HTML Template

The screenshot shows:

```html
<template>
    <lightning-card title="Content Asset File Demo">
        <a href={file} download>Download File</a>
    </lightning-card>
</template>
```

### Explanation

- `<lightning-card>` displays a Lightning card.
- `href={file}` uses the URL stored in the JavaScript property.
- `download` requests download behavior when supported by the browser and resource response.
- `Download File` is the clickable link text.

When clicked, the file may download or open depending on browser behavior and the way Salesforce serves the file.

---

## 7. Complete LWC Example

### `contentAssetFiles.html`

```html
<template>
    <lightning-card title="Content Asset File Demo">
        <div class="slds-p-around_medium">
            <a href={file} download>Download File</a>
        </div>
    </lightning-card>
</template>
```

### `contentAssetFiles.js`

```javascript
import { LightningElement } from 'lwc';

import ASSEMBLY_PDF
    from '@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf';

export default class ContentAssetFiles extends LightningElement {
    file = ASSEMBLY_PDF;
}
```

### `contentAssetFiles.js-meta.xml`

The screenshot uses API version `67.0`, exposes the component, and targets a Lightning App Page:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<LightningComponentBundle xmlns="http://soap.sforce.com/2006/04/metadata">
    <apiVersion>67.0</apiVersion>
    <isExposed>true</isExposed>
    <targets>
        <target>lightning__AppPage</target>
    </targets>
</LightningComponentBundle>
```

Use an API version supported by the Salesforce org you deploy to. The version in the screenshot is an example from the training org.

## 9. Deploy and Test

1. Save the three LWC files in the component folder.
2. Confirm the content asset exists and its API name is correct.
3. Deploy from VS Code, or use Salesforce CLI:

   ```bash
   sf project deploy start
   ```

4. Open **Setup → Lightning App Builder**.
5. Open or create a Lightning App Page.
6. Find **Content Asset Files** in the custom component list.
7. Drag it onto the page.
8. Click **Save**, then **Activate** if required.
9. Open the page and click **Download File**.

## 10. Content Asset vs. Static Resource

| Feature | Content Asset | Static Resource |
|---|---|---|
| Managed through | Salesforce Files/Libraries and content asset features | Setup → Static Resources |
| Typical use | Published content such as documents, brochures, and images for supported apps/templates | CSS, JavaScript, images, ZIPs, and other static files |
| LWC reference | `@salesforce/contentAssetUrl` | `@salesforce/resourceUrl` |
| Example import | `@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf` | `@salesforce/resourceUrl/myResource` |
| Third-party CSS/JS libraries | Not the usual choice | Common approach |

Choose the resource type that matches how the file is managed and used.

---

## 11. Sharing and Access Considerations

The creation dialog shows:

- **Let guest users see this asset file on public and login pages**
- **Make asset file available to Salesforce org users**

Do not enable public or guest access unless the file is intended for those users and your organization's security policy permits it.

If a user cannot access the asset, check whether it is available to the intended audience, whether the user can access the page, and whether the URL works in the user's Salesforce session.

---

## 12. Common Mistakes

### Incorrect API name

The import must match the asset API name:

```javascript
import ASSEMBLY_PDF
    from '@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf';
```

### Confusing the resource modules

Use `@salesforce/contentAssetUrl` for content assets and `@salesforce/resourceUrl` for Static Resources.

### Incorrect property binding

JavaScript:

```javascript
file = ASSEMBLY_PDF;
```

HTML:

```html
<a href={file} download>Download File</a>
```

The property name in the template must match the JavaScript property.

### Assuming `download` always forces a download

The `download` attribute requests download behavior, but the browser and the resource response can affect the result. Test with the actual file and user permissions.

## 13. Troubleshooting Checklist

- [ ] The content asset was created successfully.
- [ ] The import uses the exact asset API name.
- [ ] The asset is available to the intended users.
- [ ] The component deployed successfully.
- [ ] The HTML uses `href={file}` and JavaScript defines `file`.
- [ ] The component is exposed to `lightning__AppPage`.
- [ ] The user can access the page and asset.
- [ ] The browser console and network panel show no relevant errors.

# Interview Questions and Answers

## Q1. What is a Content Asset in Salesforce?

A Content Asset is a Salesforce file made available as an asset so it can be referenced in supported custom applications and Experience Cloud/community templates.

## Q2. What is `@salesforce/contentAssetUrl`?

It is an LWC scoped module used to reference a Salesforce content asset by its API name.

Example:

```javascript
import ASSEMBLY_PDF
    from '@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf';
```

## Q3. What is the syntax for importing a content asset?

The syntax shown in the training screenshot is:

```javascript
import myContentAsset from '@salesforce/contentAssetUrl/contentAssetReference';
```

## Q4. How do you display a content asset in an LWC?

Import the asset URL in JavaScript, assign it to a component property, and use that property in the HTML template.

```javascript
import ASSEMBLY_PDF
    from '@salesforce/contentAssetUrl/AFE700036_ASSEMBLY_T_pdf';

file = ASSEMBLY_PDF;
```

```html
<a href={file} download>Download File</a>
```

## Q5. What is the difference between a Content Asset and a Static Resource?

A Content Asset is managed as Salesforce content through Files/Libraries and content asset features. A Static Resource is managed through Setup and is commonly used for CSS, JavaScript, images, and ZIP archives used by Visualforce or LWC.

## Q6. What is the purpose of the `download` attribute?

It requests that the browser download the linked resource rather than simply navigate to it. Actual behavior depends on the browser and how the resource is served.

## Q7. What is the purpose of the API Name?

The API name identifies the asset in code. The import path must reference the correct API name.

## Q8. Can a PDF be used as a content asset?

Yes. The training screenshot demonstrates a PDF asset and creates a link to it.

## Q9. Why might a user be unable to access a content asset?

Possible causes include an incorrect API name, asset availability/sharing settings, user permissions, or an issue with the file URL.

## Q10. What does `isExposed` mean in the LWC metadata file?

`<isExposed>true</isExposed>` makes the component available for the supported targets listed in its metadata, such as the Lightning App Builder target in this example.

# Scenario-Based Interview Questions

## Scenario 1: The download link is blank or broken

**What would you check?**

1. Confirm the asset exists.
2. Verify the API name in `@salesforce/contentAssetUrl`.
3. Confirm the JavaScript property is assigned.
4. Verify the HTML uses the same property name.
5. Check user access and browser errors.

## Scenario 2: The file should be available to internal users but not guests

**What would you do?**

Configure the asset's sharing options according to the requirement. Do not enable guest access unless public/guest access is explicitly required and approved.

## Scenario 3: You need to load a third-party CSS library

**Would you use a Content Asset or Static Resource?**

A Static Resource is the usual choice for a third-party CSS/JavaScript library. Import it through `@salesforce/resourceUrl` and load the CSS/JavaScript using `lightning/platformResourceLoader` where needed.

## Scenario 4: The asset was renamed

**What should you verify?**

Check the current API name and update the import statement if necessary. The import path must reference the correct asset API name.

# One-Line Interview Definitions

- **Content Asset:** A Salesforce file made available as an asset for supported custom applications and templates.
- **`@salesforce/contentAssetUrl`:** LWC scoped module used to reference a Salesforce content asset.
- **Asset File Name:** The display name entered when creating the content asset.
- **API Name:** The identifier used to reference the content asset in code.
- **`href`:** HTML attribute that specifies the destination URL for a link.
- **`download`:** HTML attribute that requests download behavior for a linked resource.
- **`isExposed`:** Metadata setting that controls whether the component is available to its configured targets.
- **`lightning__AppPage`:** Metadata target that makes an LWC available on Lightning App Pages.
