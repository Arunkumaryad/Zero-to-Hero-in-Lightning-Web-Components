# Using Third-Party CSS Library in LWC

## Overview

This topic explains how to use a **third-party CSS library in Lightning Web Components (LWC)**.

The example from the training screenshots uses **Animate.css**. The library is uploaded to Salesforce as a **Static Resource** and loaded dynamically with `loadStyle()` from `lightning/platformResourceLoader`.

### Complete Flow

```text
Third-Party CSS Library
        ↓
      animate.zip
        ↓
 Salesforce Static Resource
        ↓
 @salesforce/resourceUrl
        ↓
 platformResourceLoader
        ↓
      loadStyle()
        ↓
 Animate.css loaded
        ↓
 CSS classes used in LWC
        ↓
 Animation displayed
```

---

# 1. What is a Third-Party CSS Library?

A **third-party CSS library** is a collection of reusable CSS styles created and maintained outside your own application.

It can provide:

- Animations
- Responsive layouts
- UI styling
- Icons
- Typography
- Utility classes
- Visual effects

In this example, **Animate.css** is used to add an animation without writing the animation CSS manually.

Example:

```html
<p class="animate__animated animate__bounce">
    Hii, I am enjoying this session!
</p>
```

# 5. Why Use a ZIP File?

A third-party library can contain multiple files and folders, so it can be packaged as a ZIP Static Resource.

Example:

```text
animate.zip
└── animate/
    └── animate.min.css
```

Therefore the LWC can reference:

```javascript
ANIMATE + '/animate/animate.min.css'
```

**Important:** The path must exactly match the structure inside the ZIP file.

# 8. Complete JavaScript from the Training Screenshot

```javascript
import { LightningElement } from 'lwc';

import ANIMATE from '@salesforce/resourceUrl/animate';

import { loadStyle }
    from 'lightning/platformResourceLoader';

export default class ThirdPartyStyle extends LightningElement {

    renderedCallback() {

        loadStyle(
            this,
            ANIMATE + '/animate/animate.min.css'
        )
        .then(() => {

            // success
            console.log('Style loaded successfully');

        })
        .catch(error => {

            console.error(error);

        });
    }
}
```

This is the code shown in the training material, with formatting cleaned up for readability.

# 10. What is `loadStyle()`?

Syntax:

```javascript
loadStyle(this, fileUrl)
```

Example:

```javascript
loadStyle(
    this,
    ANIMATE + '/animate/animate.min.css'
)
```

### Parameter 1

```javascript
this
```

References the current LWC component.

### Parameter 2

```javascript
ANIMATE + '/animate/animate.min.css'
```

Specifies the CSS file inside the Static Resource.

### Return value

```text
Promise
```

Therefore it can be handled with:

```javascript
.then()
.catch()
```

---

# 11. Why Use `renderedCallback()`?

The example loads the CSS library inside:

```javascript
renderedCallback()
```

`renderedCallback()` is an LWC lifecycle hook that runs after the component has rendered.

It can be used to initiate loading of external Static Resource CSS.

### Important

`renderedCallback()` can run more than once, so production code should normally use a guard to avoid repeated loading.

# 14. Complete LWC Component

## `thirdPartyStyle.html`

```html
<template>
    <lightning-card title="Third Party CSS Demo">
        <p class="animate__animated animate__bounce animate__delay-5s">
            Hii, I am enjoying this session!
        </p>
    </lightning-card>
</template>
```

## `thirdPartyStyle.js`

```javascript
import { LightningElement } from 'lwc';

import ANIMATE
    from '@salesforce/resourceUrl/animate';

import { loadStyle }
    from 'lightning/platformResourceLoader';

export default class ThirdPartyStyle extends LightningElement {

    isStyleLoaded = false;

    renderedCallback() {

        if (this.isStyleLoaded) {
            return;
        }

        loadStyle(
            this,
            ANIMATE + '/animate/animate.min.css'
        )
        .then(() => {

            this.isStyleLoaded = true;

            console.log(
                'Style loaded successfully'
            );

        })
        .catch(error => {

            console.error(
                'Unable to load Animate.css:',
                error
            );

        });
    }
}
```

---

# 15. Why Add `isStyleLoaded`?

The training screenshot directly calls `loadStyle()` in `renderedCallback()`.

A better production pattern is:

```javascript
isStyleLoaded = false;
```

Then:

```javascript
if (this.isStyleLoaded) {
    return;
}
```

After successful loading:

```javascript
this.isStyleLoaded = true;
```

Flow:

```text
Component rendered
       ↓
isStyleLoaded = false
       ↓
loadStyle()
       ↓
CSS loaded successfully
       ↓
isStyleLoaded = true
       ↓
Future renderedCallback()
       ↓
return
```

This prevents unnecessary repeated loading.

# 21. `loadStyle()` vs `loadScript()`

| Function | Purpose |
|---|---|
| `loadStyle()` | Loads CSS from a Static Resource |
| `loadScript()` | Loads JavaScript from a Static Resource |

### CSS

```javascript
import { loadStyle }
    from 'lightning/platformResourceLoader';

loadStyle(this, CSS_FILE);
```

### JavaScript

```javascript
import { loadScript }
    from 'lightning/platformResourceLoader';

loadScript(this, JS_FILE);
```

Both return a Promise.

---

# 22. Loading JavaScript and CSS Together

If a third-party library contains both JavaScript and CSS:

```javascript
import {
    loadScript,
    loadStyle
} from 'lightning/platformResourceLoader';
```

Then:

```javascript
Promise.all([
    loadScript(
        this,
        RESOURCE + '/js/library.min.js'
    ),

    loadStyle(
        this,
        RESOURCE + '/css/library.min.css'
    )
])
.then(() => {

    console.log(
        'JavaScript and CSS loaded successfully'
    );

})
.catch(error => {

    console.error(error);

});
```

`Promise.all()` waits for all supplied resource-loading Promises to complete.

# 25. Common Mistakes

## Wrong Static Resource Name

If the resource is:

```text
animate
```

use:

```javascript
import ANIMATE
    from '@salesforce/resourceUrl/animate';
```

## Wrong CSS Path

If:

```text
animate.zip
└── animate/
    └── animate.min.css
```

use:

```javascript
ANIMATE + '/animate/animate.min.css'
```

If:

```text
animate.zip
└── animate.min.css
```

use:

```javascript
ANIMATE + '/animate.min.css'
```

Always verify the ZIP structure.

## Forgetting `loadStyle()`

Importing the Static Resource does not by itself apply the CSS.

You need:

```javascript
loadStyle(
    this,
    ANIMATE + '/animate/animate.min.css'
);
```

## Wrong CSS Classes

Make sure the CSS class names match the library/version you uploaded:

```text
animate__animated
animate__bounce
animate__delay-5s
```

## Repeated Loading

Because `renderedCallback()` can run more than once, use:

```javascript
if (this.isStyleLoaded) {
    return;
}
```

## No Error Handling

Use:

```javascript
.catch(error => {
    console.error(error);
});
```

# Scenario-Based Interview Questions

## Scenario 1 — Animate a Button

**Question:** You need to apply a third-party animation library to an LWC button. What would you do?

**Answer:**

```text
1. Obtain the CSS library.
2. Package it as a ZIP if required.
```

## Scenario 3 — Repeated Loading

**Question:** Why should you use a Boolean flag with `renderedCallback()`?

**Answer:** Because `renderedCallback()` can run multiple times. The Boolean flag prevents repeated calls to `loadStyle()`.

**Question:** A third-party library requires both JS and CSS. How would you load it?

**Answer:**

Use:

```javascript
loadScript()
```

for JavaScript and:

```javascript
loadStyle()
```

for CSS.

Use:

```javascript
Promise.all()
```

when both resources must finish loading before initialization.

# One-Line Interview Definitions

**Third-Party CSS Library:** A reusable collection of CSS created outside the application's own codebase.

**Static Resource:** Salesforce storage for reusable static files such as CSS, JavaScript, images, and ZIP files.

**`@salesforce/resourceUrl`:** LWC scoped module used to reference a Salesforce Static Resource.

**`lightning/platformResourceLoader`:** Salesforce LWC module used to load JavaScript and CSS Static Resources.

**Promise:** An object representing the eventual success or failure of an asynchronous operation.

```javascript

    from '@salesforce/resourceUrl/animate';
```

```javascript
    from 'lightning/platformResourceLoader';
```

```javascript
    extends LightningElement {

    renderedCallback() {

        if (this.isStyleLoaded) {
            return;
        }

        loadStyle(
            this,
            ANIMATE + '/animate/animate.min.css'
```
