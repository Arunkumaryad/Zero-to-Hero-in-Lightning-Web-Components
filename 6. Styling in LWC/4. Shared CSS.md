This document explains **Shared CSS** in Lightning Web Components — how to write a single CSS file and reuse it across **multiple components**, instead of duplicating the same styles everywhere.

---

## 📌 What is Shared CSS?

**Definition:** As covered earlier in the *Inline and External CSS* documentation, every LWC component's CSS file (e.g., `myComponent.css`) is **automatically scoped** to that component only, thanks to the **Shadow DOM**. This means, by default, **one component's CSS cannot be reused by another component**.

**Shared CSS** solves this problem — it lets you define **common, reusable styles once**, in a separate CSS-only module, and then **import** that shared CSS file into as many components as you need — without duplicating the same CSS rules in every component's own `.css` file.

---

## 🧩 Why Use Shared CSS?

- **Avoid duplication:** If multiple components need the same styles (e.g., a custom card shadow, a specific brand color utility, consistent spacing), you don't need to copy-paste the same CSS rules into every component's `.css` file.
- **Single source of truth:** If the shared style needs to change, you only update it in **one place**, and every component using it picks up the change automatically.
- **Cleaner component-specific CSS:** Each component's own `.css` file stays focused only on styles that are truly unique to that component.

---

## 🧩 How to Create and Use Shared CSS in LWC

### Step 1: Create a CSS-Only Module Component
In LWC, a "CSS-only" module is simply a component folder that contains **only a `.css` file** (no `.js`, `.html`, or meta file needed for the shared styles to work as a module).

**Folder structure:**
```
sharedStyles/
 └── sharedStyles.css
```

**`sharedStyles.css`:**
```css
.card-highlight {
    border: 1px solid #0176d3;
    border-radius: 4px;
    padding: 12px;
}

.brand-text {
    color: #0176d3;
    font-weight: bold;
}
```

### Step 2: Import the Shared CSS into Another Component's CSS File
In the component where you want to use these shared styles, **import** the shared CSS module at the top of that component's own `.css` file:

**`myComponent.css`:**
```css
@import 'c/sharedStyles';

.myOwnUniqueStyle {
    margin-top: 10px;
}
```

- `@import 'c/sharedStyles';` — imports **all the CSS rules** from the `sharedStyles` module into this component's own CSS file.
- The imported classes (like `.card-highlight` and `.brand-text`) then become available to use **directly in this component's HTML template**, exactly as if they had been defined locally.

### Step 3: Use the Shared Classes in the Template
**`myComponent.html`:**
```html
<template>
    <div class="card-highlight">
        <p class="brand-text">This uses shared, reusable CSS.</p>
    </div>
</template>
```

## 📊 Summary Table

| Concept | Explanation |
|---|---|
| **Default CSS scoping** | Each component's `.css` file is scoped only to that component (via Shadow DOM) |
| **Shared CSS module** | A component folder containing only a `.css` file, meant to be imported elsewhere |
| **How to import** | `@import 'c/moduleName';` at the top of another component's `.css` file |
| **Benefit** | Avoids duplicating common styles across multiple components; single source of truth |

---

## ✅ Quick Recap

- By default, LWC component CSS is **isolated** to that component only — one component cannot use another's styles automatically.
- **Shared CSS** solves this by creating a **CSS-only module** (a folder with just a `.css` file) containing reusable styles.
- Other components can pull in these shared styles using `@import 'c/moduleName';` inside their own `.css` file.
- This keeps styling **DRY (Don't Repeat Yourself)** — common styles live in one place, and any component that needs them can simply import that shared module.
