# Component Composition in LWC

This document explains **Component Composition** in Lightning Web Components (LWC) — what it means, why it's useful, and the exact naming rules for referring to a child component's tag name inside a parent component's template.

---

## 📌 What is Component Composition?

> 🔎 **Definition (from training material):**
> **Composition** is **Adding Component Within the body of another component**.
> - **Composition enables you to build complex components from simpler building-block components.**

In simple words — instead of writing one giant, complicated component that does everything, you can break your UI into **smaller, simpler components**, and then **combine (compose)** them together by placing one component **inside** another. The component being placed inside is called the **child component**, and the one containing it is called the **parent component**.

This approach makes components more **reusable**, **easier to maintain**, and **easier to test**, since each smaller component focuses on doing one thing well.

---

## 🧩 How to Refer to Child Component's Name in Parent Components

> 🔎 **Definition (from training material):** How to refer child components name in parent components

When you want to use a child component inside a parent component's HTML template, you don't reference it by its JavaScript **class name** or its **file name** directly — instead, you convert its name into a specific **HTML tag format**, always prefixed with `c-`.

### Conversion Examples (from training material)

| Sno. | Component Name (camelCase) | How to Reference It in Parent's HTML |
|---|---|---|
| 1. | `childComponent` | `<c-child-component></c-child-component>` |
| 2. | `childComponentDemo` | `<c-child-component-demo></c-child-component-demo>` |
| 3. | `sampleDemoLWC` | `<c-sample-demo-l-w-c></c-sample-demo-l-w-c>` |

---

## 📐 Naming Conversion Rules

> 🔎 **Definition (from training material):**
> - **Replace capital letter with small letter and prefixed with hyphen.**
> - **Try to avoid continuous capital letters in your component name.**

Let's break down exactly how this conversion works:

### Rule 1: Replace capital letters with lowercase + a hyphen before them
This is essentially converting the component's **camelCase** name into **kebab-case** (as covered earlier in the *Naming Conventions for LWC* documentation):
- Every capital letter inside the component name becomes a **lowercase letter**, and a **hyphen (`-`)** is inserted **just before it**.
- The whole tag is then prefixed with **`c-`** (short for "custom"), since these are custom LWC components.

**Example:**
```
childComponent  →  c-child-component
```
- The capital `C` in `Component` becomes lowercase `c`, with a hyphen added before it → `child-component`.
- The `c-` prefix is added at the start → `c-child-component`.

### Rule 2: Avoid continuous/consecutive capital letters in your component name
This is why the third example looks a bit unusual:
```
sampleDemoLWC  →  c-sample-demo-l-w-c
```
- Here, `LWC` has **three consecutive capital letters** (`L`, `W`, `C`).
- Since each capital letter individually gets converted to lowercase + a preceding hyphen, `LWC` becomes `-l-w-c` (each letter separated by its own hyphen) — resulting in the slightly awkward tag `c-sample-demo-l-w-c`.
- This is exactly **why the training material recommends avoiding continuous capital letters** in your component names — because it produces messy, hard-to-read HTML tag names. A better name would have been something like `sampleDemoLwc` (only the first letter capitalized), which would cleanly convert to `c-sample-demo-lwc`.

## 🧩 Practical Example

Suppose you have a child component named `childComponentDemo`. To use it inside a parent component's HTML template:

**Child component folder/file name (camelCase):**
```
childComponentDemo/
 ├── childComponentDemo.js
 ├── childComponentDemo.html
 └── childComponentDemo.js-meta.xml
```

**Using it inside a parent component's HTML (kebab-case with `c-` prefix):**
```html
<template>
    <div>
        <c-child-component-demo></c-child-component-demo>
    </div>
</template>
```

This is how the **parent component** achieves **composition** — by embedding the **child component** directly inside its own template body.

## ✅ Quick Recap

- **Component Composition** = placing one component inside another to build complex UI from simpler, reusable pieces.
- To reference a **child component** inside a **parent component's** HTML, convert its camelCase name to **kebab-case** and prefix it with **`c-`** — e.g., `childComponent` → `<c-child-component>`.
- The conversion rule is: **replace each capital letter with a lowercase letter, prefixed by a hyphen**.
- **Avoid continuous capital letters** in your component names (like `LWC` in `sampleDemoLWC`), since each capital letter gets its own hyphen — producing awkward tag names like `c-sample-demo-l-w-c`.
