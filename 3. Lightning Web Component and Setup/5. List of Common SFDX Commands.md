# List of Common SFDX Commands

This document contains commonly used Salesforce CLI commands and their equivalent commands after the transition from the legacy SFDX CLI (`sfdx`) to the newer Salesforce CLI (`sf`).

---

# 1. SFDX CLI → SF CLI Transition

## Definition from the Video

> The SFDX CLI has been deprecated. In our videos, we have demonstrated commands using the legacy `sfdx` style. If you are now using the `sf` CLI, here are the corresponding updated commands.

### Easy Explanation

Earlier, Salesforce development commonly used commands beginning with:

```bash
sfdx
```

The newer Salesforce CLI uses:

```bash
sf
```

Therefore, when working with current Salesforce CLI commands, we should prefer the newer `sf` syntax.

# 3. Create Scratch Org

## Legacy SFDX Command

```bash
sfdx force:org:create -s -f config/project-scratch-def.json -d 30 -a recipes
```

## New SF Command

```bash
sf org create scratch -d -f config/project-scratch-def.json -y 30 -a recipes
```

---

## Changes

According to the screenshot:

- Add the `scratch` subcommand.
- The `"assign default org"` flag changes from `-s` to `-d`.
- The scratch org duration flag changes from `-d` to `-y`.

### Easy Explanation

The new command makes the Scratch Org concept explicit by using:

```bash
org create scratch
```

The important flag changes are:

```text
Old                    New
--------------------------------
-s                     -d
-d                     -y
```

So:

```bash
sfdx force:org:create
```

becomes:

```bash
sf org create scratch
```

# 13. Legacy vs New CLI Structure

The old SFDX commands generally followed a structure similar to:

```text
sfdx force:<topic>:<command>
```

For example:

```bash
sfdx force:org:create
```

The newer SF CLI uses a more readable structure:

```text
sf <topic> <command>
```

For example:

```bash
sf org create scratch
```

Another example:

```text
Old:
sfdx force:data:tree:import

New:
sf data import tree
```

---

# 14. Easy Way to Remember

Think of the new SF CLI as:

```text
sf
 ↓
TOPIC
 ↓
ACTION
 ↓
TARGET
```

Example:

```bash
sf org create scratch
```

Breakdown:

```text
sf       → Salesforce CLI
org      → Organization topic
create   → Action
scratch  → Type of org
```

Another example:

```bash
sf org delete scratch
```

```text
sf       → Salesforce CLI
org      → Organization topic
delete   → Action
scratch  → Type of org
```
