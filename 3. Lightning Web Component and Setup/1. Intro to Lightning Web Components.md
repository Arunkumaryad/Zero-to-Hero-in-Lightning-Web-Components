# Intro to Lightning Web Components

Lightning Web Components (LWC) is Salesforce's modern programming model for building reusable user interface components on the Salesforce Platform.

This section covers the introduction to the Lightning Framework, evolution of the web stack, Aura vs LWC, Lightning Web Components, interoperability between Aura and LWC, and Lightning Experience.

# 1. Lightning Framework

## Definition

> **The Lightning Component framework is a UI framework for developing single page applications for mobile and desktop devices.**

Lightning Components use two programming models:

1. **Aura Components Model**
2. **Lightning Web Components Model**

---

## Easy Explanation

The Lightning Component Framework provides the technology used to build modern Salesforce user interfaces.

It allows developers to create reusable UI components instead of building the entire page as one large application.

Salesforce provides two major component programming models:

### Aura Components

Aura is Salesforce's older component programming model.

```text
Aura Component
      ↓
Lightning Framework
      ↓
Salesforce UI
```

### Lightning Web Components

LWC is Salesforce's modern component programming model based heavily on standard web technologies.

```text
LWC
 ↓
HTML
CSS
JavaScript
Web Standards
 ↓
Salesforce UI
```

# 8. What is Lightning Web Components?

## Actual Definition from the Screenshot

> **Lightning Web Components is a new programming model for building Lightning components. It uses the core concepts of Web Standards.**

---

## Easy Explanation

Lightning Web Components, commonly called **LWC**, is Salesforce's modern programming model for creating reusable UI components.

LWC uses technologies that are already part of the web platform, especially:

```text
HTML
CSS
JavaScript
Web Components
DOM
Events
Modules
```

Instead of learning a completely different programming language, a developer can use standard web development concepts.

# 9. Benefits of Lightning Web Components

The screenshot lists the following benefits:

### 1. Lightweight framework

LWC is designed to be lightweight and relies heavily on browser/web-platform capabilities.

---

### 2. Better Performance

Using modern web standards and optimized rendering helps components perform efficiently.

---

### 3. No need to learn a different framework to develop applications in Salesforce

Developers can use familiar web technologies such as:

```text
HTML
CSS
JavaScript
```

while developing Salesforce components.

---

### 4. Interoperability with Lightning Aura Components

LWC and Aura Components can work together.

This is important when an existing Salesforce application contains Aura components and you want to introduce LWC gradually.

---

### 5. Better testing using Jest

LWC supports testing with **Jest**, allowing developers to write unit tests for component JavaScript behavior.

---

### 6. Better Security

LWC is built with Salesforce security architecture and web-platform standards in mind.

# 11. Coexistence and Interoperability

## Definition from the Screenshot

They can work together.

# 17. LWC Component Structure

A typical LWC component contains multiple files.

```text
myComponent/
│
├── myComponent.html
├── myComponent.js
├── myComponent.js-meta.xml
└── myComponent.css
```

### HTML

Responsible for the component's UI.

```html
<template>
    <lightning-card title="Hello LWC">
        <p>Hello Salesforce!</p>
    </lightning-card>
</template>
```

---

### JavaScript

Responsible for component logic.

```javascript
import { LightningElement } from 'lwc';

export default class MyComponent extends LightningElement {

}
```

---

### CSS

Responsible for component-specific styling.

```css
p {
    font-size: 20px;
}
```

---

### Metadata XML

Controls where the component can be used.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<LightningComponentBundle xmlns="http://soap.sforce.com/2006/04/metadata">
    <apiVersion>XX.0</apiVersion>
    <isExposed>true</isExposed>

    <targets>
        <target>lightning__HomePage</target>
    </targets>
</LightningComponentBundle>
```

# 19. Key Differences: Aura vs LWC

| Feature | Aura | LWC |
|---|---|---|
| Programming model | Aura Component Model | Lightning Web Component Model |
| JavaScript | Older JavaScript patterns | Modern JavaScript |
| Web Standards | Less dependent on standards | Strongly based on Web Standards |
| Syntax | Aura-specific syntax | HTML + JavaScript + CSS |
| Performance | Older rendering approach | More optimized modern approach |
| Jest | Less commonly associated | Strong testing support |
| Modern JS | More limitations | ES6+ features |
| Interoperability | Can work with LWC | Can coexist with Aura |

# 23. Final Takeaways
