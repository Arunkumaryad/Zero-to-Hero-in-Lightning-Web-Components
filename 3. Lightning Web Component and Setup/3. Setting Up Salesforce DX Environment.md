# Setting Up Salesforce DX Environment

Salesforce DX (Developer Experience) provides a set of tools and practices that help developers build, test, collaborate on, and release Salesforce applications more efficiently.

---

# 1. Salesforce Developer Experience (DX)

## Definition

> It is a set of tools that streamlines the entire development life cycle. It improves team development and collaboration, facilitates automated testing and continuous integration, and makes the release cycle more efficient and agile.

### Easy Explanation

Salesforce DX provides developers with tools that make the Salesforce development process easier and more organized.

It helps developers to:

- Develop Salesforce applications
- Work with other developers
- Manage source code
- Test applications
- Deploy changes
- Use version control
- Automate development processes
- Improve the release process

In simple words:

```text
Salesforce DX
      ↓
Development
      ↓
Testing
      ↓
Collaboration
      ↓
Deployment
      ↓
Release
```

# 3. Visual Studio Code

## What is Visual Studio Code?

Visual Studio Code, commonly called **VS Code**, is a source-code editor used by Salesforce developers to write and manage Salesforce code.

It provides an environment where developers can work with Salesforce metadata and source code.

### Salesforce Development Using VS Code

VS Code can be used to work with:

- Apex
- Lightning Web Components
- Aura Components
- JavaScript
- HTML
- CSS
- SOQL
- Salesforce Metadata

Example:

```text
VS Code
   │
   ├── Apex
   ├── LWC
   ├── Aura
   ├── SOQL
   ├── HTML
   ├── CSS
   └── JavaScript
```

---

# 4. Why Do We Use VS Code?

VS Code provides a convenient development environment for Salesforce developers.

It allows developers to:

- Create Salesforce projects
- Write Apex code
- Create Lightning Web Components
- Retrieve metadata
- Deploy metadata
- Work with Git
- Manage source code
- Use Salesforce CLI commands

Example development flow:

```text
VS Code
   ↓
Write Code
   ↓
Save Code
   ↓
Deploy
   ↓
Salesforce Org
```

# 5. Salesforce CLI

## What is Salesforce CLI?

**Salesforce CLI** stands for **Salesforce Command Line Interface**.

It is a command-line tool used to interact with Salesforce environments and perform development and deployment tasks.

### Easy Explanation

Instead of performing every operation manually through the Salesforce UI, developers can use commands in the terminal.

For example:

```text
Developer
    ↓
VS Code Terminal
    ↓
Salesforce CLI
    ↓
Salesforce Org
```

---

# 6. What Can We Do Using Salesforce CLI?

Salesforce CLI can be used for many development tasks.

Examples include:

- Create Salesforce projects
- Authenticate with Salesforce Org
- Retrieve metadata
- Deploy metadata
- Run Apex tests
- Execute SOQL
- Manage scratch orgs
- Work with source code
- Automate development tasks

---

# 7. Example Salesforce CLI Commands

### Check Salesforce CLI

```bash
sf --version
```

This checks whether Salesforce CLI is installed.

---

### Login to Salesforce

```bash
sf org login web
```

This command can be used to authenticate a Salesforce Org through the browser.

---

### Display Connected Orgs

```bash
sf org list
```

This displays Salesforce orgs that are available through the CLI.

---

### Create a Salesforce Project

```bash
sf project generate --name MySalesforceProject
```

This creates a Salesforce DX project.

---

# 8. Salesforce Extension Pack

## What is Salesforce Extension Pack?

**Salesforce Extension Pack** is a collection of Visual Studio Code extensions that provides Salesforce development functionality inside VS Code.

It makes Salesforce development easier by providing tools and features directly inside the editor.

---

# 9. Why Do We Need Salesforce Extension Pack?

Without Salesforce-specific extensions, VS Code is mainly a general-purpose code editor.

The Salesforce Extension Pack adds Salesforce development capabilities.

It helps developers work with:

```text
Apex
LWC
Aura
SOQL
Salesforce Metadata
Salesforce CLI
```

# 15. Basic Salesforce DX Environment Setup

## Step 1: Install Visual Studio Code

Download and install Visual Studio Code.

After installation, open VS Code.

---

## Step 2: Install Salesforce CLI

Install Salesforce CLI on your system.

After installation, open the terminal and verify the installation:

```bash
sf --version
```

If the CLI is installed correctly, Salesforce CLI version information will be displayed.

---

## Step 3: Install Salesforce Extension Pack

Open VS Code.

Go to:

```text
Extensions
   ↓
Search: Salesforce Extension Pack
```

Install the Salesforce Extension Pack.

---

## Step 4: Create a Salesforce Project

Open the VS Code terminal and create a Salesforce project.

Example:

```bash
sf project generate --name MySalesforceProject
```

The project structure will contain Salesforce DX project files.

---
