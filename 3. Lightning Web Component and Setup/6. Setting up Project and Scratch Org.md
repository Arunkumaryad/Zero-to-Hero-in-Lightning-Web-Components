# Setting up Project and Scratch Org

This document explains the basic setup required to create a Salesforce DX project, authorize a Salesforce org, and create a Scratch Org.

---

# 1. Dev Hub vs Scratch Org

## Dev Hub

### Definition from the Screenshot

> **Dev Hub** - It is the main Salesforce org that you will use to create and manage your scratch orgs.

### Easy Explanation

The **Dev Hub** is the main Salesforce org used to create and manage Scratch Orgs.

Think of it like:

```text
Dev Hub
   │
   ├── Scratch Org 1
   ├── Scratch Org 2
   ├── Scratch Org 3
   └── Scratch Org 4




1. Create Project
   ↓
sfdx force:project:create -n "LWC project"

2. Authorize Org
   ↓
sfdx force:auth:web:login -a lwclearning -d

3. Configure Scratch Org
   ↓
config/project-scratch-def.json

4. Add Sample Data
   ↓
"hasSampleData": "true"

5. Create Scratch Org
   ↓
sfdx force:org:create -a lwcScratchOne -d 30 \
-f config/project-scratch-def.json -s

6. If Dev Hub configuration error occurs
   ↓
sfdx force:config:set defaultdevhubusername=<DevHub Username>
