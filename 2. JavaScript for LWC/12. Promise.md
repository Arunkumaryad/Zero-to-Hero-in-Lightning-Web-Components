# Promise

> **A Promise** is an object that represents the eventual completion (success) or failure of an asynchronous operation. Instead of returning the final result immediately, a Promise returns a placeholder that will provide the result in the future.

Promises are one of the most important concepts in modern JavaScript and are extensively used in **Lightning Web Components (LWC)** for handling Apex calls, REST API requests, file uploads, and asynchronous operations.

---

# 📖 Overview

JavaScript is a **single-threaded** language, meaning it executes one task at a time. However, many operations like fetching data from a server or reading a file take time to complete.

Promises help us manage these asynchronous operations without blocking the execution of other code.

# Why Do We Need Promises?

Imagine your application needs to:

- Fetch records from Salesforce
- Call an external REST API
- Upload a file
- Read a file

These operations take some time.

Without Promises, JavaScript would become difficult to manage due to nested callbacks (Callback Hell).

Promises provide a cleaner and more readable way to handle asynchronous tasks.

# Understanding Promise States

## 1. Pending

### Definition

A Promise starts in the **Pending** state.

This means:

- Task has started.
- Result is not available yet.

```
Pending
```

↓

Waiting...

---

## 2. Fulfilled (Resolved)

### Definition

The Promise is **fulfilled** when the asynchronous operation completes successfully.

```
Pending

↓

Resolved

↓

Fulfilled
```

Example

```
Data fetched successfully
```

---

## 3. Rejected

### Definition

If something goes wrong while executing the task, the Promise becomes **Rejected**.

```
Pending

↓

Rejected
```

Example

```
Network Error
```

---

# Promise Flow

```
                Promise

                   |

             Pending State

           /               \

     resolve()          reject()

         |                  |

    Fulfilled          Rejected

         |                  |

      then()             catch()
```

# Creating a Promise

## Syntax

```javascript
let promise = new Promise(function(resolve, reject){

});
```

Where

- **resolve()** → Called when the operation is successful.
- **reject()** → Called when the operation fails.

---

# Example from the Video

```javascript
function checkIsSuccess(data){

    return new Promise(function(resolve, reject){

        if(data === "success"){

            return resolve("successfully executed.");

        }

        else{

            return reject("unsuccessfully rejected");

        }

    });

}

checkIsSuccess("success")

.then(function(result){

    console.log(result);

})

.catch(function(error){

    console.error(error);

});
```

---

## Output

```
successfully executed.
```

# resolve()

## Definition

`resolve()` marks a Promise as **fulfilled**.

It sends the success value to the `.then()` block.

Example

```javascript
resolve("Record Saved");
```

↓

```javascript
.then(function(result){

    console.log(result);

});
```

Output

```
Record Saved
```

---

# reject()

## Definition

`reject()` marks a Promise as **failed**.

It sends the error message to `.catch()`.

Example

```javascript
reject("Something went wrong");
```

↓

```javascript
.catch(function(error){

    console.log(error);

});
```

Output

```
Something went wrong
```

---

# then()

## Definition

`then()` executes when the Promise is resolved successfully.

Syntax

```javascript
promise.then(function(result){

});
```

Example

```javascript
Promise.resolve("Success")

.then(function(result){

    console.log(result);

});
```

Output

```
Success
```

---

# catch()

## Definition

`catch()` executes when the Promise is rejected.

Syntax

```javascript
promise.catch(function(error){

});
```

Example

```javascript
Promise.reject("Error")

.catch(function(error){

    console.log(error);

});
```

Output

```
Error
```

# Real World Examples

## Example 1

Fetching User Data

```javascript
function getUser(){

    return new Promise(function(resolve){

        resolve({

            name:"Arun",

            city:"Delhi"

        });

    });

}

.then(function(user){

    console.log(user);

});
```

Output

```javascript

    name:"Arun",
    city:"Delhi"
}
```

---

## Example 2

Promise with Delay

```javascript
let promise = new Promise(function(resolve){

    setTimeout(function(){

        resolve("Task Completed");

    },2000);

});

promise.then(function(result){

    console.log(result);

});
```

Output (after 2 seconds)

```
Task Completed
```

# Promise Chaining

```javascript
Promise.resolve(10)

.then(num=>{

    return num*2;

})

.then(num=>{

    return num+5;

})

.then(result=>{

    console.log(result);

});
```

Output

```

```

# Best Practices

✅ Always use `.catch()` to handle errors.

✅ Return Promises from asynchronous functions.

✅ Keep Promise chains simple.

✅ Use meaningful success and error messages.

✅ Use `async/await` for cleaner code when possible.

---

# Common Mistakes

## Mistake 1

Forgetting `.catch()`

❌ Wrong

```javascript
fetchData()

.then(result=>{

    console.log(result);

});
```

If an error occurs, it will not be handled.

---

### Correct

```javascript
fetchData()

.then(result=>{

    console.log(result);

})

.catch(error=>{

    console.log(error);

});
```

---

## Mistake 2

Calling resolve() and reject() together.

❌ Wrong

```javascript
resolve("Success");

reject("Error");
```

Only the first call is considered.

---

## Mistake 3

Not returning the Promise.

❌ Wrong

```javascript
function test(){

    new Promise(...);

}
```

---

### Correct

```javascript
function test(){

    return new Promise(...);

}
```

# Key Takeaways

- A Promise is an object that represents the future result of an asynchronous operation.
- Promises help avoid callback hell and make asynchronous code easier to read.
- Every Promise has three states: **Pending**, **Fulfilled**, and **Rejected**.
- Use `resolve()` to indicate success and `reject()` to indicate failure.
- Handle successful results using `.then()` and errors using `.catch()`.
- Promises are widely used in **Lightning Web Components (LWC)** for Apex calls, REST APIs, file uploads, and data fetching.
