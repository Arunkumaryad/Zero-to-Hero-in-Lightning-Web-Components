# Understanding the Correction

Many beginners think that only `var` supports global scope.

That is **not correct**.

The correction is:

- `var` supports global scope.
- `let` supports global scope.
- `const` supports global scope.

The actual difference is **how they behave on the global object**.

---

# Global Scope vs Global Object

These two concepts are different.

## Global Scope

A variable declared outside any function or block is said to be in the **global scope**.

Example

```javascript
let city = "Delhi";
```

`city` is globally scoped because it is declared outside any function.

---

## Global Object

In browsers, the global object is `window` (or `this` in non-module scripts).

Variables declared with `var` become properties of the global object.

Variables declared with `let` and `const` do **not** become properties of the global object.

---

# Example Using var

```javascript
var x = "global";

console.log(this.x);
```

Output

```
global
```

### Explanation

`var` creates a property on the global object.

It behaves like:

```javascript
window.x = "global";
```

Therefore,

```javascript
console.log(this.x);
```

returns

```
global
```

---

# Example Using let

```javascript
let y = "global";

console.log(this.y);
```

Output

```
undefined
```

### Explanation

Although `y` is globally scoped, it is **not attached to the global object**.

Therefore,

```javascript
this.y
```

returns

```
undefined
```

---

# Example Using const

```javascript
const z = "Salesforce";

console.log(this.z);
```

Output

```
undefined
```

### Explanation

`const` behaves exactly like `let` in this case.

It is globally scoped but **does not become a property of the global object**.

---

# Why Does This Matter?

This behavior prevents accidental pollution of the global object.

Older JavaScript applications often had issues because many `var` variables became global properties.

Modern JavaScript avoids this problem by using `let` and `const`.

# Why Should You Use let and const?

Modern JavaScript recommends using `let` and `const` because they:

- Avoid accidental global object pollution.
- Provide block scope.
- Make code safer and easier to maintain.
- Reduce unexpected bugs caused by `var`.

---

# Best Practices

✅ Use `const` whenever the value does not need to change.

✅ Use `let` when the value needs to be updated.

✅ Avoid using `var` in modern JavaScript projects.

✅ Remember that `let` and `const` can be globally scoped but are not attached to the global object.

---

# Common Mistakes

❌ Assuming only `var` supports global scope.

❌ Confusing **global scope** with the **global object**.

❌ Expecting `this.variableName` to work for variables declared with `let` or `const`.

❌ Using `var` unnecessarily in new projects.
