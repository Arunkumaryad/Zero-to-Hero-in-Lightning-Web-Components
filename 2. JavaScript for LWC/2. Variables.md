# Variables in JavaScript

> Variables are one of the fundamental concepts in JavaScript. They are used to store data that can be used and manipulated throughout a program. In modern JavaScript, variables can be declared using **var**, **let**, and **const**, each having different behaviors and scopes. Understanding these differences is essential for writing clean and efficient JavaScript code, especially in Lightning Web Components (LWC).

---

# 📖 Overview

A variable is a named container used to store data values.

You can think of a variable as a box that stores information, and you can access or modify the stored value whenever required.

Example:

```
Name → Arun

Age → 22

City → Delhi
```

Here, **Name**, **Age**, and **City** are variables.

# 💡 Simple Definition

Variables are used to store information in memory so that it can be used later in the program.

Example

```javascript
let name = "Arun";
```

Here,

- `let` → Keyword
- `name` → Variable
- `"Arun"` → Value

---

# Variable Declaration

Variables can be declared using three keywords:

- `var`
- `let`
- `const`

Example

```javascript
var city = "Delhi";

let age = 22;

const country = "India";
```

---

# JavaScript Identifiers

Variable names are called **Identifiers**.

JavaScript identifiers are **case-sensitive**.

Example

```javascript
let name = "Arun";

let Name = "Kumar";
```

These are treated as **two different variables**.

---

# Assigning Values

A value can be assigned while declaring the variable or later before using it.

Example

### Assign while declaration

```javascript
let name = "Arun";
```

### Assign later

```javascript
let name;

name = "Arun";
```

Both are valid.

---

# Variable Scope

A variable's **scope** determines where it can be accessed.

JavaScript mainly has:

- Global Scope
- Function Scope
- Block Scope

---

# 1. Global Scope

A globally declared variable can be accessed from anywhere in the program.

Example

```javascript
var company = "Salesforce";

function show(){

    console.log(company);

}
```

---

# 2. Function Scope

Variables declared inside a function can only be accessed within that function.

Example

```javascript
function test(){

    var age = 22;

}

console.log(age);
```

Output

```
ReferenceError
```

---

# 3. Block Scope

Variables declared inside `{ }` are only accessible within that block.

Example

```javascript
if(true){

    let city = "Delhi";

}

console.log(city);
```

Output

```
ReferenceError
```

---

# var Keyword

`var` was introduced in older versions of JavaScript.

Example

```javascript
var a = "Test";

console.log(a);

var a = "Test declared Again";

console.log(a);
```

Output

```
Test

Test declared Again
```

### Function Scope Example

```javascript
function abc(){

    var x = 10;

    console.log(x);

}

abc();
```

Output

```
10
```

### Important Points

- Function Scoped
- Global Scoped
- Can be reassigned
- Can be redeclared
- Does not support block scope

---

# let Keyword

`let` was introduced in ES6 and is the preferred choice when a variable's value needs to change.

Example

```javascript
let name = "Arun";

name = "Arun Kumar";

console.log(name);
```

Output

```
Arun Kumar
```

### Function Scope Example

```javascript
function test(){

    let y = 50;

    console.log(y);

}

test();
```

Output

```
50
```

Trying to access `y` outside the function:

```javascript
console.log(y);
```

Output

```
ReferenceError
```

### Important Points

- Block Scoped
- Function Scoped
- Can be reassigned
- Cannot be redeclared in the same scope

---

### Important Note (From the Video)

> **let variables can be updated but not re-declared.**

Example

```javascript
let name = "Arun";

name = "Salesforce";   // ✅ Allowed

let name = "Test";     // ❌ Error
```

---

# const Keyword

`const` is used when the value should never change after initialization.

Example

```javascript
const course = "Zero to Hero";

console.log(course);
```

Trying to change it:

```javascript
const course = "LWC";
```

Output

```
Error
```

### Function Scope Example

```javascript
function abc(){

    const x = 20;

    console.log(x);

}

abc();
```

Output

```
20
```

### Block Scope Example

```javascript
if(true){

    const y = 40;

    console.log(y);

}
```

Output

```
40
```

Trying to access outside the block:

```javascript
console.log(y);
```

Output

```
ReferenceError
```

### Important Points

- Block Scoped
- Function Scoped
- Cannot be reassigned
- Cannot be redeclared

---

### Important Note (From the Video)

> **const variables can neither be updated nor re-declared.**

Example

```javascript
const country = "India";

country = "USA";     // ❌ Error
```

---

# Difference Between var, let and const

| Feature | var | let | const |
|----------|-----|-----|--------|
| Global Scope | ✅ Yes | ❌ No | ❌ No |
| Function Scope | ✅ Yes | ✅ Yes | ✅ Yes |
| Block Scope | ❌ No | ✅ Yes | ✅ Yes |
| Can be Reassigned | ✅ Yes | ✅ Yes | ❌ No |
| Can be Redeclared | ✅ Yes | ❌ No | ❌ No |

---

# Which Keyword Should You Use?

### Use `const`

When the value should never change.

Example

```javascript
const PI = 3.14;
```

---

### Use `let`

When the value needs to change later.

Example

```javascript
let counter = 1;

counter++;
```

---

### Use `var`

Only when working with old JavaScript code or legacy projects.

In modern JavaScript and LWC, avoid using `var`.

---

# Variables in LWC

Variables are used to store component data.

Example

```javascript
import { LightningElement } from 'lwc';

export default class HelloWorld extends LightningElement {

    message = "Hello Salesforce";

}
```

The variable `message` stores the text displayed in the component.

---

# Best Practices

✅ Use `const` by default.

✅ Use `let` only when the value changes.

✅ Avoid using `var` in modern JavaScript.

✅ Use meaningful variable names.

✅ Follow camelCase naming convention.

Example

```javascript
let firstName;

let totalAmount;

let accountName;
```

---

# Common Mistakes

❌ Using `var` in new projects.

❌ Redeclaring a `let` variable.

❌ Trying to change a `const` variable.

❌ Accessing block-scoped variables outside their block.

❌ Using unclear variable names.

# Interview Questions

### 1. What is a variable?

A variable is a container used to store data values.

---

### 2. Which keywords are used to declare variables in JavaScript?

- `var`
- `let`
- `const`

---

### 3. What is the difference between `let` and `const`?

- `let` can be reassigned but cannot be redeclared in the same scope.
- `const` cannot be reassigned or redeclared after initialization.

---

### 4. What is the difference between `var` and `let`?

- `var` is function-scoped and does not support block scope.
- `let` is block-scoped and cannot be redeclared in the same scope.

---

### 5. Why should we avoid using `var`?

Because it does not support block scope and can be redeclared, which may lead to unexpected behavior and bugs.

---

### 6. Are JavaScript variable names case-sensitive?

Yes. `name` and `Name` are considered different identifiers.

---

### 7. Which keyword is recommended in modern JavaScript?

Use `const` whenever possible. Use `let` only if the value needs to change.

---

# Key Takeaways

- Variables are containers used to store data values.
- JavaScript provides three keywords for declaring variables: `var`, `let`, and `const`.
- JavaScript identifiers are case-sensitive.
- Variables can be assigned values during declaration or later before use.
- `var` is function-scoped and can be redeclared.
- `let` is block-scoped, can be reassigned, but cannot be redeclared in the same scope.
- `const` is block-scoped and cannot be reassigned or redeclared.
- In modern JavaScript and Lightning Web Components, prefer `const` by default and use `let` only when reassignment is required.

# Summary

Variables are the foundation of JavaScript programming, allowing developers to store and manage data throughout an application. JavaScript offers three ways to declare variables—`var`, `let`, and `const`—each with different scoping and reassignment rules. Understanding these differences is essential for writing clean, predictable, and maintainable code, especially when developing Lightning Web Components (LWC). Following modern best practices by using `const` and `let` helps improve code quality and reduces common programming errors.
