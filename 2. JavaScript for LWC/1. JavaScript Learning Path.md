# 3. Null vs Undefined

One of the most commonly asked interview topics.

### Undefined

A variable has been declared but no value has been assigned.

Example

```javascript
let name;

console.log(name);
```

Output

```
undefined
```

---

### Null

Represents an intentional empty value.

Example

```javascript
let name = null;
```

Output

```
null
```

---

# Difference

| Undefined | Null |
|------------|------|
| Value not assigned | Empty value assigned intentionally |
| Automatic | Assigned manually |

# 4. Arrow Functions

Introduced in ES6.

Traditional Function

```javascript
function greet(){

    console.log("Hello");

}
```

Arrow Function

```javascript
const greet = () => {

    console.log("Hello");

}
```

### Benefits

- Short syntax
- Cleaner code
- Commonly used in LWC

---

# 5. Spread Operator

The spread operator copies or expands arrays and objects.

Example

```javascript
const numbers = [1,2,3];

const newNumbers = [...numbers];
```

Object Example

```javascript
const user = {

    name:"Arun"

};

const updatedUser = {

    ...user,

    city:"Delhi"

};
```

### Used in LWC

Frequently used to update tracked arrays and objects.

---

# 6. Destructuring

Extract values from arrays or objects easily.

Object Example

```javascript
const user = {

    name:"Arun",

    city:"Delhi"

};

```

Array Example

```javascript
const colors = ["Red","Blue"];

const [first, second] = colors;
```

# 14. setTimeout() vs setInterval()

### setTimeout()

Runs only once after a specified delay.

Example

```javascript
setTimeout(() => {

    console.log("Hello");

},2000);
```

---

### setInterval()

Runs repeatedly after every specified interval.

Example

```javascript
setInterval(() => {

    console.log("Running");

},1000);
```

---

# Difference

| setTimeout() | setInterval() |
|--------------|---------------|
| Executes once | Executes repeatedly |
| Used for delayed execution | Used for repeated execution |

# Best Practices

✅ Use `let` and `const` instead of `var`.

✅ Prefer Arrow Functions where appropriate.

✅ Use Template Literals instead of string concatenation.

✅ Keep functions small and reusable.

✅ Use Destructuring and the Spread Operator for cleaner code.

✅ Understand asynchronous programming before working with APIs.

❌ Using `var` unnecessarily.

# Interview Questions

### 1. What is JavaScript?

JavaScript is a scripting or programming language that allows you to implement complex features on web pages and brings interactivity to web pages.

---

### 2. Why is JavaScript important for LWC?

JavaScript provides the business logic for Lightning Web Components, including event handling, API calls, data manipulation, and UI interactions.

---

### 3. What is the difference between `let`, `const`, and `var`?

- `var` is function-scoped and can be redeclared.
- `let` is block-scoped and can be reassigned.
- `const` is block-scoped and cannot be reassigned.

---

### 4. What is the difference between `null` and `undefined`?

- `undefined` means a variable has been declared but not assigned a value.
- `null` is an intentionally assigned empty value.

---

### 5. What is an Arrow Function?

An Arrow Function is a shorter syntax for writing functions, introduced in ES6, and is widely used in modern JavaScript and LWC.

---

### 6. What is the Spread Operator?

The Spread Operator (`...`) expands or copies arrays and objects, making updates easier and more readable.

---

### 7. What are Promises?

Promises are JavaScript objects used to handle asynchronous operations and can be in Pending, Fulfilled, or Rejected states.

---

### 8. What are JavaScript Modules?

Modules allow code to be split into reusable files using `import` and `export`.

---

### 9. What is the purpose of `querySelector()` in LWC?

`querySelector()` is used to access and interact with HTML elements within a Lightning Web Component's template.

---

### 10. What is the difference between `setTimeout()` and `setInterval()`?

- `setTimeout()` executes a function once after a specified delay.
- `setInterval()` executes a function repeatedly at specified intervals.
