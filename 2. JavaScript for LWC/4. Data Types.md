# Data Types in JavaScript

> JavaScript provides different **data types** to store different kinds of values. Every variable in JavaScript has a data type that determines what type of value it can hold and what operations can be performed on it.

---

# 📖 Overview

A **data type** defines the kind of value stored in a variable. JavaScript is a **dynamically typed language**, meaning you do not need to declare a variable's data type explicitly. The JavaScript engine automatically determines the data type based on the assigned value.

Example:

```javascript
let age = 22;          // Number
let name = "Arun";     // String
let isStudent = true;  // Boolean
```

# JavaScript Data Types

JavaScript has **8 basic data types**.

| S.No | Data Type | Description |
|------|-----------|-------------|
| 1 | Number | Stores numeric values (integer and decimal). |
| 2 | String | Stores text enclosed in quotes. |
| 3 | Boolean | Stores `true` or `false`. |
| 4 | BigInt | Stores very large integers beyond the safe Number limit. |
| 5 | Undefined | A variable that has been declared but not assigned a value. |
| 6 | Null | Represents an intentional empty or unknown value. |
| 7 | Object | Stores collections of key-value pairs and complex data. |
| 8 | Symbol | Stores unique and immutable identifiers. |

# Primitive and Non-Primitive Data Types

JavaScript data types can be divided into two categories.

## Primitive Data Types

Primitive values store a **single value**.

- Number
- String
- Boolean
- BigInt
- Undefined
- Null
- Symbol

Example:

```javascript
let age = 22;
let city = "Delhi";
let isAdmin = false;
```

---

## Non-Primitive Data Type

The only non-primitive data type is:

- Object

Arrays, Dates, Functions, and many built-in objects are all special kinds of objects.

Example:

```javascript
let person = {
    name: "Arun",
    age: 22
};
```

---

# typeof Operator

The `typeof` operator returns the data type of a variable.

Syntax

```javascript
typeof variableName
```

Example

```javascript
let name = "Arun";

console.log(typeof name);
```

Output

```
string
```

---

# 1. Number

A Number represents numeric values.

Example

```javascript
var x = 10.66;

console.log(typeof x);
```

Output

```
number
```

Numbers can be:

- Integer
- Decimal
- Negative
- Positive

Examples

```javascript
10

20.5

-100
```

---

# 2. BigInt

BigInt is used for very large integers that exceed JavaScript's safe integer limit.

Example

```javascript
var y = 1068768768n;

console.log(typeof y);
```

Output

```
bigint
```

Notice the **`n`** at the end of the number.

---

# 3. String

A String stores text.

Example

```javascript
var name = "nikhil";

console.log(typeof name);
```

Output

```
string
```

Strings can be written using:

```javascript
"Hello"

'Hello'

`Hello`
```

---

# 4. Boolean

Boolean stores only two values.

- true
- false

Example

```javascript
var isMonday = true;

console.log(typeof isMonday);
```

Output

```
boolean
```

Booleans are commonly used in conditions.

```javascript
if(isMonday){
    console.log("Today is Monday");
}
```

---

# 5. Undefined

A variable that has been declared but not assigned a value has the type `undefined`.

Example

```javascript
var z;

console.log(typeof z);
```

Output

```
undefined
```

---

# 6. Object

Objects store data as key-value pairs.

Example

```javascript
var obj = {};

console.log(typeof obj);
```

Output

```
object
```

Another example

```javascript
var person = {
    name: "Arun",
    age: 22
};
```

---

# Arrays

Arrays are also objects in JavaScript.

Example

```javascript
var arr = [];

console.log(typeof arr);
```

Output

```
object
```

Although arrays are a separate data structure, `typeof` returns `"object"`.

---

# 7. Symbol

A Symbol creates unique values.

Example

```javascript
var sym = Symbol("id");

console.log(typeof sym);
```

Output

```
symbol
```

Symbols are commonly used to create unique object properties.

---

# 8. Null

`null` represents an intentional absence of a value.

Example

```javascript
var x1 = 10;

x1 = null;

console.log(x1);
```

Output

```
null
```

> **Note:** If you run `typeof null`, JavaScript returns `"object"`. This is a historical behavior in JavaScript.

# Best Practices

✅ Use `typeof` to identify the type of a variable.

✅ Use `null` when you intentionally want to indicate "no value."

✅ Use `undefined` only for uninitialized variables.

✅ Use `BigInt` only when numbers exceed the safe integer limit.

✅ Use objects to represent structured data.

---

# Common Mistakes

❌ Thinking arrays have the type `"array"`.

```javascript
typeof []
```

Output

```
object
```

---

❌ Confusing `null` with `undefined`.

`undefined`

```javascript
let x;
```

`null`

```javascript
let x = null;
```

---

❌ Forgetting the `n` suffix for BigInt.

Incorrect

```javascript
12345678901234567890
```

Correct

```javascript
12345678901234567890n
```

# Interview Questions

### 1. How many basic data types are there in JavaScript?

There are **8 basic data types**:

- Number
- String
- Boolean
- BigInt
- Undefined
- Null
- Object
- Symbol

---

### 2. Which operator is used to determine a variable's data type?

The `typeof` operator.

Example

```javascript
typeof name;
```

---

### 3. What is the difference between `null` and `undefined`?

- `undefined` means a variable has been declared but not assigned a value.
- `null` represents an intentional empty value.

---

### 4. What is the output?

```javascript
typeof []
```

Output

```
object
```

---

### 5. Why is BigInt used?

BigInt is used to store integers larger than JavaScript's safe integer limit (`Number.MAX_SAFE_INTEGER`).

---

### 6. What is a Symbol?

A Symbol is a primitive data type that creates unique and immutable values, commonly used as unique object property keys.
