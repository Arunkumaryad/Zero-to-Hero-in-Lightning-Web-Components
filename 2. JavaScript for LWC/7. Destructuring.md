# Destructuring

> **Destructuring** is an ES6 feature in JavaScript that allows you to **unpack values from arrays or properties from objects into separate variables**. It makes your code shorter, cleaner, and easier to read.

---

# 📖 Overview

JavaScript provides two commonly used data structures:

- **Array**
- **Object**

Normally, we access their values using indexes or property names.

### Without Destructuring

```javascript
let arr = ["Salesforce", "Amazon"];

console.log(arr[0]);
console.log(arr[1]);
```

Output

```
Salesforce
Amazon
```

With **Destructuring**, JavaScript allows us to extract values directly into variables.

# What is Destructuring?

Destructuring is an ES6 syntax that lets you extract values from arrays or objects and assign them to variables in a single statement.

Instead of accessing each value individually, destructuring makes the code more readable and concise.

---

# Why Use Destructuring?

Without destructuring:

```javascript
let company1 = arr[0];
let company2 = arr[1];
```

With destructuring:

```javascript
let [company1, company2] = arr;
```

The second approach is shorter and easier to understand.

---

# 1. Array Destructuring

Array destructuring extracts values based on their **position (index)**.

### Example

```javascript
let arr = ["Salesforce", "Amazon"];

let [company1, company2] = arr;

console.log(company1);
console.log(company2);
```

Output

```
Salesforce
Amazon
```

### Explanation

```javascript
company1 = arr[0];
company2 = arr[1];
```

JavaScript automatically assigns values according to their order in the array.

---

## Without Destructuring

```javascript
let arr = ["Salesforce", "Amazon"];

console.log(arr[0]);
console.log(arr[1]);
```

Output

```
Salesforce
Amazon
```

---

## With Destructuring

```javascript
let arr = ["Salesforce", "Amazon"];

let [company1, company2] = arr;

console.log(company1);
console.log(company2);
```

Output

```
Salesforce
Amazon
```

The output is the same, but the code is much cleaner.

---

# 2. Object Destructuring

Object destructuring extracts values based on **property names**.

### Example

```javascript
let obj = {

    name: "Salesforce",

    age: 45,

    type: "CRM"

};

let { name, age, type } = obj;

console.log(name);

console.log(age);

console.log(type);
```

Output

```
Salesforce

45

CRM
```

---

## Explanation

Instead of writing:

```javascript
console.log(obj.name);

console.log(obj.age);

console.log(obj.type);
```

You can directly extract the properties:

```javascript
let { name, age, type } = obj;
```

Now each property becomes an independent variable.

---

# How Array Destructuring Works

JavaScript matches values by **position**.

Example

```javascript
let numbers = [10, 20, 30];

let [a, b, c] = numbers;

console.log(a);

console.log(b);

console.log(c);
```

Output

```
10

20

30
```

---

# How Object Destructuring Works

JavaScript matches values by **property name**, not by order.

Example

```javascript
let user = {

name: "Arun",

city: "Delhi"

};

let {

city,

name

} = user;

console.log(name);

console.log(city);
```

Output

```
Arun

Delhi
```

Even though `city` appears first, JavaScript correctly matches properties by name.

---

# Array vs Object Destructuring

| Array Destructuring | Object Destructuring |
|----------------------|----------------------|
| Uses square brackets `[]` | Uses curly braces `{}` |
| Matches values by position | Matches values by property name |
| Order matters | Property names matter |
| Mostly used with arrays | Mostly used with objects |

# Best Practices

✅ Use array destructuring for arrays.

```javascript
const [first, second] = array;
```

---

✅ Use object destructuring for objects.

```javascript
const { name, age } = user;
```

---

✅ Use meaningful variable names.

```javascript
const { email } = customer;
```

# Common Mistakes

### Mistake 1

Using `{}` for arrays.

❌ Wrong

```javascript
let { a, b } = [1,2];
```

✅ Correct

```javascript
let [a, b] = [1,2];
```

---

### Mistake 2

Using `[]` for objects.

❌ Wrong

```javascript
let [name] = user;
```

✅ Correct

```javascript
let { name } = user;
```

---

### Mistake 3

Expecting array order not to matter.

```javascript
let arr = [10,20];

let [b,a] = arr;
```

Output

```
b = 10

a = 20
```

Array destructuring always follows index order.

# Destructuring in LWC

Destructuring is widely used in Lightning Web Components when working with JavaScript objects and arrays.

Example:

};

It helps write cleaner and more maintainable LWC code.

# Summary

**Destructuring** is a modern JavaScript feature that simplifies the process of extracting values from arrays and objects. Instead of accessing elements using indexes or property names repeatedly, destructuring allows you to assign them directly to variables in a single statement. Array destructuring works based on the position of elements, while object destructuring works based on property names. It improves code readability, reduces repetition, and is commonly used in **Lightning Web Components (LWC)** and other modern JavaScript frameworks.
