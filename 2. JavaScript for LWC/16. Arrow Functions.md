# Arrow Functions

> **Arrow Functions** provide a shorter and cleaner syntax for writing functions in JavaScript. They were introduced in **ES6 (ECMAScript 2015)** and automatically inherit the `this` value from their surrounding scope.

Arrow functions are widely used in modern JavaScript, React, Node.js, and **Lightning Web Components (LWC)** because they make code more concise and solve many `this` keyword problems.

---

# 📖 Overview

In JavaScript, functions are used to perform specific tasks. Before ES6, functions were written using the `function` keyword.

ES6 introduced **Arrow Functions (`=>`)**, which provide a shorter syntax and automatically bind `this` to the surrounding scope.

# What is an Arrow Function?

An Arrow Function is a shorter way to write a function in JavaScript.

Instead of using the `function` keyword, we use the **arrow operator (`=>`)**.

---

# Normal Function

### Syntax

```javascript
function functionName(parameters) {

    // code

}
```

### Example

```javascript
function sum(a) {

    let total = a + 10;

    return total;

}

console.log(sum(10));
```

### Output

```
20
```

---

# Arrow Function

### Syntax

```javascript
const functionName = (parameters) => {

    // code

};
```

### Example

```javascript
let add = (a) => {

    let sum = a + 20;

    return sum;

};

console.log(add(50));
```

### Output

```
70
```

---

# Arrow Function without Return

If the function contains only **one statement**, the `return` keyword and curly braces can be omitted.

```javascript
const getName = () => "Arun";

console.log(getName());
```

### Output

```
Arun
```

---

# Arrow Function with Multiple Parameters

```javascript
const add = (a, b) => {

    return a + b;

};

console.log(add(10, 20));
```

### Output

```
30
```

---

# Arrow Function with One Parameter

Parentheses are optional if there is only one parameter.

```javascript
const square = number => number * number;

console.log(square(5));
```

### Output

```
25
```

---

# Arrow Function with No Parameters

```javascript
const greet = () => {

    console.log("Hello JavaScript");

};

greet();
```

### Output

```
Hello JavaScript
```

# Understanding `this` in Normal Functions

One of the biggest differences between normal functions and arrow functions is the behavior of the **`this`** keyword.

Example

```javascript
let obj = {

    name: "Arun",

    getName: function () {

        console.log(this.name);

        function fullName() {

            console.log("My Full Name is " + this.name + " Kumar");

        }

        fullName();

    }

};

obj.getName();
```

### Output

```
Arun

My Full Name is undefined Kumar
```

### Why?

Inside `fullName()`, `this` refers to the global object instead of the object `obj`.

Therefore,

```javascript
this.name
```

becomes

```
undefined
```

---

# Solving the Problem using Arrow Functions

Arrow functions inherit `this` from the surrounding function.

Example

```javascript
let obj1 = {

    name: "Arun",

    getName: function () {

        console.log(this.name);

        const fullName = () => {

            console.log("My Full Name is " + this.name + " Kumar");

        }

        fullName();

    }

};

obj1.getName();
```

### Output

```
Arun

My Full Name is Arun Kumar
```

### Why?

The arrow function does not create its own `this`.

Instead, it uses the `this` from the surrounding `getName()` function.

---

# Normal Function vs Arrow Function

| Normal Function | Arrow Function |
|-----------------|----------------|
| Uses `function` keyword | Uses `=>` operator |
| Creates its own `this` | Inherits `this` from parent scope |
| Can be used as constructors | Cannot be constructors |
| Has `arguments` object | Does not have its own `arguments` object |
| Longer syntax | Shorter syntax |

# When Should You Use Arrow Functions?

Arrow functions are perfect for:

- Callback functions
- Array methods (`map`, `filter`, `reduce`)
- Promise callbacks
- Event handlers (in many cases)
- LWC JavaScript methods
- Short utility functions

Example

```javascript
numbers.map(number => number * 2);
```

---

# When NOT to Use Arrow Functions

Avoid arrow functions:

- As object methods when you need the object's own `this`
- As constructors
- When you need the `arguments` object

# Best Practices

✅ Use arrow functions for callbacks.

```javascript
arr.map(item => item * 2);
```

---

✅ Use arrow functions for Promise handlers.

```javascript
fetchData()

.then(result => console.log(result));
```

---

✅ Use meaningful parameter names.

```javascript
users.map(user => user.name);
```

# Common Mistakes

## Mistake 1

Forgetting parentheses when returning an object.

❌ Wrong

```javascript
const user = () => { name: "Arun" };
```

✅ Correct

```javascript
const user = () => ({ name: "Arun" });
```

---

## Mistake 2

Using arrow functions as constructors.

❌ Wrong

```javascript
const Person = () => {};
new Person();
```

Arrow functions cannot be used with `new`.

---

## Mistake 3

Using arrow functions where object methods require their own `this`.

Sometimes a normal function is more appropriate.

# Summary

Arrow Functions are one of the most useful features introduced in ES6. They provide a concise syntax for writing functions and automatically inherit the `this` value from their surrounding scope, eliminating many common issues with traditional functions. They are widely used with array methods, asynchronous programming, and modern frameworks like **React** and **Lightning Web Components (LWC)**. Understanding when to use Arrow Functions—and when to use regular functions—is essential for writing clean and efficient JavaScript.
