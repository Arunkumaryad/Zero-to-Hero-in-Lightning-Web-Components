JavaScript provides many built-in methods to perform operations such as transforming data, filtering elements, checking conditions, sorting, reducing values, and iterating over arrays. These methods are widely used in **Lightning Web Components (LWC)** because they make code shorter, cleaner, and easier to maintain.

# General Syntax

Most array methods follow this syntax:

```javascript
array.methodName(function(currentItem, index, array) {

});
```

Where:

- **currentItem** → Current element being processed.
- **index** → Index of current element.
- **array** → Original array.

---

# 1. map()

## Definition

`map()` loops through every element of an array and creates a **new array** based on the value returned by the callback function.

It never modifies the original array.

---

## Syntax

```javascript
array.map(function(currentItem, index, array){

});
```

---

## Example

```javascript
let arr = [2,3,5,7,9,10];

let newArray = arr.map(function(currentItem,index,array){

    console.log(
        `currentItem is ${currentItem}
         index ${index},
         array ${array}`
    );

    return currentItem * 2;

});

console.log(arr);

console.log(newArray);
```

### Output

```javascript
currentItem is 2 index 0
currentItem is 3 index 1
currentItem is 5 index 2
currentItem is 7 index 3
currentItem is 9 index 4
currentItem is 10 index 5

[2,3,5,7,9,10]

[4,6,10,14,18,20]
```

---

## Explanation

Each value is multiplied by **2** and stored in a new array.

Original array

```javascript
[2,3,5,7,9,10]
```

New array

```javascript
[4,6,10,14,18,20]
```

---

## LWC Example

```javascript
this.records = this.records.map(record => {
    return {
        ...record,
        selected: false
    };
});
```

# 2. filter()

## Definition

`filter()` returns a **new array** containing only those elements that satisfy a given condition.

---

## Syntax

```javascript
array.filter(function(currentItem,index,array){

});
```

---

## Example

```javascript
let filteredValues = arr.filter(function(currentItem){

    return currentItem > 5;

});

console.log(filteredValues);
```

### Output

```javascript
[7,9,10]
```

---

## Explanation

Only numbers greater than **5** are returned.

---

## LWC Example

```javascript
let activeUsers = users.filter(user => user.active);
```

---

# 3. every()

## Definition

`every()` checks whether **every element** satisfies a condition.

Returns:

- true
- false

---

## Syntax

```javascript
array.every(function(currentItem){

});
```

---

## Example

```javascript
let age = [32,33,18,40];

let isAllAdult = age.every(function(currentItem){

    return currentItem >= 18;

});

console.log(isAllAdult);
```

### Output

```javascript
true
```

---

## Explanation

All values are greater than or equal to **18**.

Hence,

```javascript
true
```

---

## Another Example

```javascript
[20,18,12].every(num => num>=18)
```

Output

```javascript
false
```

---

# 4. some()

## Definition

`some()` returns **true** if **at least one** element satisfies the condition.

---

## Syntax

```javascript
array.some(function(currentItem){

});
```

---

## Example

```javascript
let ageList = [32,33,18,40];

let isAdult = ageList.some(function(currentItem){

    return currentItem > 32;

});

console.log(isAdult);
```

### Output

```javascript
true
```

---

## Explanation

Since **33** and **40** satisfy the condition,

Result:

```javascript
true
```

---

## Another Example

```javascript
[5,8,2].some(num=>num>10)
```

Output

```javascript
false
```

---

# Difference Between every() and some()

| every() | some() |
|----------|---------|
| Checks all elements | Checks at least one element |
| Returns true only if every element matches | Returns true if one element matches |
| Stops on first false | Stops on first true |

---

# 5. sort()

## Definition

`sort()` sorts the elements of an array.

---

## Sorting Strings

```javascript
var names = ["Nikhil","John","Smith","Arun"];

console.log(names.sort());
```

### Output

```javascript
["Arun","John","Nikhil","Smith"]
```

---

## Sorting Numbers

Without compare function:

```javascript
[10,2,50].sort();
```

Output

```javascript
[10,2,50]
```

Wrong because numbers are sorted as strings.

---

### Correct Way

```javascript
var nums = [10,39,12,80,54];

let sortedValues = nums.sort(function(a,b){

    return a-b;

});

console.log(sortedValues);
```

### Output

```javascript
[10,12,39,54,80]
```

---

### Descending Order

```javascript
nums.sort((a,b)=>b-a);
```

Output

```javascript
[80,54,39,12,10]
```

---

# 6. reduce()

## Definition

`reduce()` reduces an entire array into a **single value**.

The reduction happens from **left to right**.

---

## Syntax

```javascript
array.reduce(function(total,currentValue,index,array){

},initialValue)
```

---

## Example

```javascript
let num = [12,78,30];

let sum = num.reduce(function(total,currentItem){

    return total + currentItem;

},0);

console.log(sum);
```

### Output

```javascript
120
```

---

## Explanation

```
0+12=12

12+78=90

90+30=120
```

Final answer

```
120
```

---

## Find Maximum

```javascript
let numbers = [10,20,50,15];

let max = numbers.reduce((a,b)=>{

    return Math.max(a,b);

});

console.log(max);
```

Output

```
50
```

---

## LWC Example

```javascript
let totalAmount = orders.reduce((sum,item)=>{

    return sum + item.amount;

},0);
```

---

# 7. forEach()

## Definition

`forEach()` executes a callback function once for each element in the array.

It **does not return a new array**.

---

## Syntax

```javascript
array.forEach(function(currentItem,index,array){

});
```

---

## Example

```javascript
num.forEach(function(currentItem){

    console.log(currentItem);

});
```

### Output

```javascript
12

78

30
```

---

## Explanation

Each element is printed one by one.

---

## Difference Between map() and forEach()

| map() | forEach() |
|---------|-----------|
| Returns new array | Returns undefined |
| Used for transformation | Used for iteration |
| Chainable | Not chainable |

# Best Practices

✅ Use `map()` when creating a new array.

✅ Use `filter()` to remove unwanted data.

✅ Use `every()` for validation.

✅ Use `some()` to check for existence.

✅ Always provide a compare function when sorting numbers.

✅ Use `reduce()` for totals, averages, and calculations.

✅ Use `forEach()` only when you don't need a return value.

---

# Common Mistakes

## Mistake 1

Using `map()` without returning a value.

❌ Wrong

```javascript
arr.map(item=>{

    item*2;

});
```

---

### Correct

```javascript
arr.map(item=>{

    return item*2;

});
```

---

## Mistake 2

Sorting numbers without a compare function.

❌ Wrong

```javascript
[100,5,20].sort();
```

Output

```javascript
[100,20,5]
```

---

### Correct

```javascript
[100,5,20].sort((a,b)=>a-b);
```

---

## Mistake 3

Expecting `forEach()` to return a new array.

❌ Wrong

```javascript
let result = arr.forEach(item=>item*2);
```

Result

```
undefined
```

Use `map()` instead.

# Key Takeaways

- `map()` creates a new transformed array.
- `filter()` returns elements that match a condition.
- `every()` checks if all elements satisfy a condition.
- `some()` checks if at least one element satisfies a condition.
- `sort()` arranges elements in order.
- `reduce()` converts an array into a single value.
- `forEach()` executes a function for every element without returning a new array.
- These methods are heavily used in **Lightning Web Components (LWC)** for handling lists, records, validations, UI updates, and calculations.
