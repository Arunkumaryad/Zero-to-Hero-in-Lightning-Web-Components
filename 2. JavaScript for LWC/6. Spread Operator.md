# Spread Operator (`...`)

> The **Spread Operator (`...`)** is one of the most useful features introduced in **ES6 (ECMAScript 2015)**. It allows you to **expand iterable objects (like arrays and strings)** into individual elements, **merge arrays and objects**, and **create shallow copies** of arrays and objects.

---

# 📖 Overview

The **Spread Operator** is represented by **three consecutive dots (`...`)**.

It is used to **expand** or **spread** the elements of an iterable (such as an array or string) or the properties of an object into another array or object.

### Syntax

```javascript
...
```

Example:

```javascript
const arr = [1, 2, 3];

console.log(...arr);
```

Output

```
1 2 3
```

Instead of printing the array, the spread operator expands each element individually.

# What is the Spread Operator?

The spread operator expands the contents of an array, string, or object into individual elements or properties.

Instead of manually copying or combining values, JavaScript can do it in a single line using `...`.

Example

```javascript
const numbers = [10, 20, 30];

console.log(...numbers);
```

Output

```
10 20 30
```

---

# 1. Expanding a String

Strings are iterable in JavaScript.

Using the spread operator converts each character into an array element.

### Example

```javascript
let greeting = "Hello Everyone";

let charList = [...greeting];

console.log(charList);
```

Output

```javascript
[
'H','e','l','l','o',
' ','E','v','e','r',
'y','o','n','e'
]
```

### Explanation

The string is expanded character by character into an array.

---

# 2. Combining Arrays

The spread operator is commonly used to merge multiple arrays.

### Example

```javascript
let arr1 = ["Amazon", "Google"];

let arr2 = ["Facebook", "Microsoft"];

let arr3 = [...arr1, ...arr2];

console.log(arr3);
```

Output

```javascript
[
'Amazon',
'Google',
'Facebook',
'Microsoft'
]
```

### Explanation

Instead of using loops or `concat()`, the spread operator merges both arrays.

---

# 3. Adding Elements to an Array

You can easily insert new values while copying an array.

### Example

```javascript
let arr4 = ["a", "b", "c"];

let arr5 = ["Arun", ...arr4];

console.log(arr5);
```

Output

```javascript
[
'Arun',
'a',
'b',
'c'
]
```

### Explanation

The new value `"Arun"` is inserted before the existing array elements.

Similarly,

```javascript
let arr6 = [...arr4, "Arun"];
```

adds `"Arun"` at the end.

---

# 4. Combining Objects

Spread Operator can merge multiple objects.

### Example

```javascript
let obj1 = {
    name: "Salesforce",
    age: 25,
    date: "05/08/2026"
};

let obj2 = {
    name: "Amazon",
    age: 45
};

let obj3 = {
    ...obj1,
    ...obj2
};

console.log(obj3);
```

Output

```javascript
{
name: "Amazon",
age: 45,
date: "05/08/2026"
}
```

### Explanation

If two objects contain the same property, the value from the **last object** overrides the previous one.

---

# 5. Creating a Shallow Copy

Without Spread Operator

```javascript
let arr10 = ["x", "y", "z"];

let arr11 = arr10;

arr11.push("Arun");

console.log(arr10);
console.log(arr11);
```

Output

```javascript
["x","y","z","Arun"]

["x","y","z","Arun"]
```

### Why?

Both variables point to the **same array in memory**.

Changing one also changes the other.

---

## Correct Way (Using Spread Operator)

```javascript
let arr12 = ["a", "b", "c"];

let arr13 = [...arr12];

arr13.push("Arun");

console.log(arr12);

console.log(arr13);
```

Output

```javascript
["a","b","c"]

["a","b","c","Arun"]
```

### Explanation

Spread Operator creates a **new array**.

Both arrays become independent.

---

# What is a Shallow Copy?

A **shallow copy** creates a new array or object, but **nested objects are still shared**.

Example

```javascript
let arr = [1,2,3];

let copy = [...arr];
```

The array is copied.

But if the array contains objects, those objects are **not copied**.

---

# 6. Nested Object Copy Problem

### Example

```javascript
let arrObj = [

    { name: "Salesforce" },

    { name: "Amazon" }

];

let arrObj1 = [...arrObj];

arrObj1[0].name = "CRM";

console.log(arrObj1);

console.log(arrObj);
```

Output

```javascript
[
{name:"CRM"},
{name:"Amazon"}
]

[
{name:"CRM"},
{name:"Amazon"}
]
```

### Explanation

Although the array is copied,

the objects inside it are **still pointing to the same memory location**.

This is called a **Shallow Copy**.

---

# 7. Deep Copy (JSON Hack)

To completely duplicate nested objects,

the video demonstrates this approach.

```javascript
let arrObj3 = JSON.parse(

JSON.stringify(arrObj)

);

arrObj3[0].name = "Facebook";

console.log(arrObj3);

console.log(arrObj);
```

Output

```javascript
arrObj3

[
{name:"Facebook"},
{name:"Amazon"}
]

arrObj

[
{name:"CRM"},
{name:"Amazon"}
]
```

### Explanation

`JSON.stringify()` converts the object into a JSON string.

`JSON.parse()` converts the string back into a brand-new object.

Now both objects are independent.

---

# Shallow Copy vs Deep Copy

| Feature | Shallow Copy | Deep Copy |
|----------|-------------|-----------|
| Creates new array/object | ✅ | ✅ |
| Copies nested objects | ❌ | ✅ |
| Nested object reference shared | Yes | No |
| Spread Operator | ✅ | ❌ |
| JSON.parse(JSON.stringify()) | ❌ | ✅ |

# Advantages of Spread Operator

- Cleaner syntax
- Easy to read
- Faster than manual loops for simple copying
- Merge arrays easily
- Merge objects easily
- Add elements anywhere
- Create shallow copies quickly

---

# Limitations

Spread Operator creates only a **shallow copy**.

Nested objects remain shared.

Example

```javascript
let user = {

name:"Arun",

address:{

city:"Delhi"

}

};

let copy = {

...user

};

copy.address.city="Mumbai";

console.log(user.address.city);
```

Output

```
Mumbai
```

Because the nested object is still shared.

---

# Best Practices

✅ Use Spread Operator for arrays.

✅ Use it to merge objects.

✅ Use it for immutable updates in React and LWC.

✅ Use Deep Copy when working with nested objects.

# Common Mistakes

### Mistake 1

```javascript
let a = [1,2];

let b = a;
```

Not a copy.

Both variables point to the same array.

---

### Mistake 2

```javascript
let copy = [...original];
```

Thinking this performs a deep copy.

It only creates a shallow copy.

---

### Mistake 3

Modifying nested objects after shallow copy.

```javascript
copy[0].name="CRM";
```

This also modifies the original object.

# Interview Questions

### 1. What is the Spread Operator?

It is an ES6 feature represented by `...` used to expand arrays, strings, or objects into individual elements or properties.

---

### 2. What are the uses of the Spread Operator?

- Expand strings
- Merge arrays
- Merge objects
- Create shallow copies
- Add elements to arrays

---

### 3. Does Spread Operator create a Deep Copy?

No.

It creates only a shallow copy.

---

### 4. What is the difference between Shallow Copy and Deep Copy?

Shallow Copy shares nested object references.

Deep Copy creates completely independent copies.

---

### 5. How can you create a Deep Copy?

One common approach is:

```javascript
JSON.parse(JSON.stringify(object))
```

> **Note:** This works well for simple JSON-compatible objects but does not preserve functions, `Date`, `Map`, `Set`, `undefined`, or circular references.

---

### 6. Which object overrides properties when merging?

```javascript

...obj1,

...obj2

}
```

The **last object (`obj2`)** overrides duplicate properties.

# Key Takeaways

- The Spread Operator is written as `...`.
- It expands arrays, objects, and strings.
- It is commonly used to merge arrays and objects.
- It can add elements to arrays easily.
- It creates shallow copies of arrays and objects.
- Nested objects are **not** deeply copied.
- Use `JSON.parse(JSON.stringify())` (or modern alternatives like `structuredClone()` where available) when you need a deep copy of simple data structures.
- The last object's properties overwrite earlier ones during object merging.

---

# Summary

The **Spread Operator (`...`)** is a powerful ES6 feature that makes JavaScript code cleaner and easier to maintain. It is widely used to expand strings into arrays, merge arrays and objects, add new elements, and create shallow copies without modifying the original data. While it simplifies many everyday tasks, it's important to remember that it performs only a **shallow copy**, meaning nested objects still share references. For complex nested data, a deep copy approach is required. Mastering the Spread Operator is essential for modern JavaScript development and is especially useful when working with frameworks such as **Lightning Web Components (LWC)**, where immutable data updates are a common practice.
