# setTimeout vs setInterval

> `setTimeout()` and `setInterval()` are JavaScript timing functions provided by the **Window object**. They allow you to execute code after a delay or repeatedly after a fixed interval.

These methods are commonly used in JavaScript, React, and **Lightning Web Components (LWC)** for creating delays, polling APIs, animations, notifications, and automatic updates.

---

# 📖 Overview

JavaScript is a **single-threaded** language, but it can perform asynchronous operations using browser APIs like **setTimeout()** and **setInterval()**.

These methods schedule a callback function to run **later**, allowing the browser to continue executing other code.

# 📖 Actual Definition (Based on the Video)

## setTimeout()

> **The `setTimeout()` is a method of the Window object. The `setTimeout()` sets a timer and executes a callback function after the timer expires.**

---

## setInterval()

> **The `setInterval()` is a method of the Window object. The `setInterval()` repeatedly calls a function with a fixed delay between each call.**

---

# What is setTimeout()?

`setTimeout()` executes a function **only once** after a specified amount of time.

It is useful when you want to delay an action.

---

# Syntax

```javascript
setTimeout(function () {

    // Code to execute

}, delayInMilliseconds);
```

---

# Example

```javascript
setTimeout(function () {

    console.log("Hello");

}, 2000);
```

### Output

After **2 seconds**

```
Hello
```

---

# Using Arrow Function

```javascript
setTimeout(() => {

    console.log("Welcome");

}, 3000);
```

### Output

After **3 seconds**

```
Welcome
```

---

# What is setInterval()?

`setInterval()` repeatedly executes a function after a fixed interval until it is stopped.

It is useful when you want to perform an action continuously.

---

# Syntax

```javascript
setInterval(function () {

    // Code to execute repeatedly

}, delayInMilliseconds);
```

---

# Example

```javascript
setInterval(function () {

    console.log("Arun");

}, 5000);
```

### Output

Every **5 seconds**

```
Arun

Arun

Arun

Arun

...
```

The function continues running until it is stopped.

---

# clearTimeout()

Sometimes we schedule a timeout but later decide to cancel it.

For that, JavaScript provides **clearTimeout()**.

### Example

```javascript
let timer = setTimeout(() => {

    console.log("Hello");

}, 5000);

clearTimeout(timer);
```

### Output

Nothing is printed because the timer was cancelled.

---

# clearInterval()

`setInterval()` keeps running forever.

To stop it, use **clearInterval()**.

### Example

```javascript
let interval = setInterval(() => {

    console.log("Running...");

}, 1000);

setTimeout(() => {

    clearInterval(interval);

    console.log("Interval Stopped");

}, 5000);
```

### Output

```
Running...

Running...

Running...

Running...

Interval Stopped
```

---

# Difference Between setTimeout() and setInterval()

| setTimeout() | setInterval() |
|--------------|---------------|
| Executes only once | Executes repeatedly |
| Runs after a specified delay | Runs after every specified interval |
| Used for delayed execution | Used for repeated execution |
| Can be cancelled using `clearTimeout()` | Can be cancelled using `clearInterval()` |

# Best Practices

✅ Always clear intervals when they are no longer needed.

```javascript
clearInterval(intervalId);
```

---

✅ Store timer IDs.

```javascript
let timer = setTimeout(...);
```

---

✅ Use arrow functions for cleaner syntax.

```javascript
setTimeout(() => {

    console.log("Done");

}, 1000);
```

# Common Mistakes

## Mistake 1

Calling the function instead of passing it.

❌ Wrong

```javascript
setTimeout(showMessage(), 2000);
```

✅ Correct

```javascript
setTimeout(showMessage, 2000);
```

---

## Mistake 2

Forgetting to stop `setInterval()`.

```javascript
setInterval(() => {

    console.log("Running");

}, 1000);
```

This runs forever unless you call

```javascript
clearInterval()
```

---

## Mistake 3

Using milliseconds incorrectly.

```javascript
1000 = 1 second

2000 = 2 seconds

5000 = 5 seconds
```

# Key Takeaways

- `setTimeout()` executes a function **once** after a delay.
- `setInterval()` executes a function **repeatedly** after a fixed interval.
- Both methods belong to the **Window object**.
- `clearTimeout()` stops a scheduled timeout.
- `clearInterval()` stops a running interval.
- These methods are essential for asynchronous programming in JavaScript and are commonly used in **LWC** for delayed actions, timers, polling, and UI updates.

---

# Summary

`setTimeout()` and `setInterval()` are powerful timing functions in JavaScript that help execute code asynchronously. While `setTimeout()` is used for one-time delayed execution, `setInterval()` repeatedly executes code at fixed intervals until stopped. Understanding these methods, along with `clearTimeout()` and `clearInterval()`, is essential for building responsive web applications and Lightning Web Components that rely on timers, delayed actions, or periodic updates.
