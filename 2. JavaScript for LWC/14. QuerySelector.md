# QuerySelector

> **querySelector()** and **querySelectorAll()** are JavaScript DOM methods used to select HTML elements using CSS selectors. These methods allow developers to access and manipulate elements dynamically.

Both methods are commonly used in **JavaScript** and **Lightning Web Components (LWC)** to interact with elements in the DOM.

---

# 📖 Overview

Whenever we need to change the content, style, or behavior of an HTML element using JavaScript, we first need to access that element.

JavaScript provides two powerful methods for this purpose:

- `querySelector()`
- `querySelectorAll()`

These methods accept **CSS selectors** such as element names, classes, IDs, or attributes to locate elements in the document.

# 📖 Actual Definition (Based on the Video)

## querySelector

The **querySelector()** method returns the **first element** that matches a specified CSS selector(s) in the document.

### Syntax

```javascript
document.querySelector(selector);
```

---

## querySelectorAll

The **querySelectorAll()** method returns **all elements** in the document that match a specified CSS selector(s), as a **static NodeList object**.

### Syntax

```javascript
document.querySelectorAll(selector);
```

---

# What is querySelector()?

`querySelector()` searches the document for the **first element** that matches the given CSS selector.

If multiple elements match the selector, only the **first one** is returned.

If no matching element exists, it returns **null**.

---

# Syntax

```javascript
document.querySelector("selector");
```

---

### HTML


### JavaScript


# What is querySelectorAll()?

`querySelectorAll()` returns **all matching elements** instead of just the first one.

The returned object is called a **NodeList**, which can be looped through using `forEach()` or a `for...of` loop.

---

# Syntax

```javascript
document.querySelectorAll("selector");
```

---

# Example

### HTML

```html
<p>One</p>
<p>Two</p>
<p>Three</p>
```

### JavaScript

```javascript
const paragraphs = document.querySelectorAll("p");

console.log(paragraphs);
```

Output

```
NodeList(3)
```

---

# Access Individual Elements

```javascript
const paragraphs = document.querySelectorAll("p");

console.log(paragraphs[0].textContent);

console.log(paragraphs[1].textContent);
```

Output

```
One

Two
```

---

# Loop Through All Elements

```javascript
const paragraphs = document.querySelectorAll("p");

paragraphs.forEach(item => {
    console.log(item.textContent);
});
```

Output

```
One

Two

Three
```

# Difference Between querySelector() and querySelectorAll()

| querySelector() | querySelectorAll() |
|-----------------|--------------------|
| Returns first matching element | Returns all matching elements |
| Returns a single Element | Returns a NodeList |
| Returns null if no element found | Returns an empty NodeList if no element found |
| No looping required | Usually requires looping |

# querySelector in Lightning Web Components (LWC)

In LWC, direct access to the global `document` object is discouraged because components use **Shadow DOM** for encapsulation.

Instead of:

```javascript
document.querySelector();
```

Use:

```javascript
this.template.querySelector();
```

---

## Example

### HTML

```html
<template>

    <lightning-input class="name"></lightning-input>

</template>
```

### JavaScript

```javascript
const input = this.template.querySelector(".name");

console.log(input.value);
```

---

# querySelectorAll in LWC

```javascript
const buttons = this.template.querySelectorAll("lightning-button");

buttons.forEach(btn => {
    console.log(btn.label);
});
```

# Best Practices

✅ Use `querySelector()` when only one element is needed.

✅ Use `querySelectorAll()` when multiple elements are required.

✅ In LWC, always use `this.template.querySelector()` instead of `document.querySelector()`.

✅ Check for `null` before using the returned element.

Example:

```javascript
const btn = document.querySelector(".save");

if (btn) {
    btn.click();
}
```

---

# Common Mistakes

## Mistake 1

Using `querySelector()` expecting multiple elements.

❌ Wrong

```javascript
const items = document.querySelector("li");
```

Only the first `<li>` is returned.

---

### Correct

```javascript
const items = document.querySelectorAll("li");
```

---

## Mistake 2

Using `document.querySelector()` in LWC.

❌ Wrong

```javascript
document.querySelector(".input");
```

---

### Correct

```javascript
this.template.querySelector(".input");
```

---

## Mistake 3

Not checking for `null`.

❌ Wrong

```javascript
document.querySelector(".box").style.color = "red";
```

If `.box` doesn't exist, an error occurs.

---

### Correct

```javascript
const box = document.querySelector(".box");

if (box) {
    box.style.color = "red";
}
```

# Interview Questions

### 1. What is `querySelector()`?

It returns the **first HTML element** that matches a specified CSS selector.

---

### 2. What is `querySelectorAll()`?

It returns **all matching HTML elements** as a static `NodeList`.

---

### 3. What happens if no element is found using `querySelector()`?

It returns `null`.

---

### 4. What does `querySelectorAll()` return if no elements match?

It returns an **empty NodeList**.

### 5. What is the difference between `querySelector()` and `querySelectorAll()`?

- `querySelector()` returns only the **first matching element**.
- `querySelectorAll()` returns **all matching elements**.

---

### 6. Why is `document.querySelector()` not recommended in LWC?

Because LWC uses **Shadow DOM**, components should access their own DOM using `this.template.querySelector()` for proper encapsulation and security.


---

### 8. How do you select an element with an ID?

# Key Takeaways

- `querySelector()` returns the **first** matching element.
- `querySelectorAll()` returns **all** matching elements as a `NodeList`.
- Both methods use **CSS selectors**.
- `querySelectorAll()` is useful when working with multiple elements.
- In **LWC**, use `this.template.querySelector()` and `this.template.querySelectorAll()` instead of the global `document` object.
- Always check for `null` when using `querySelector()` to avoid runtime errors.

---

# Summary

`querySelector()` and `querySelectorAll()` are essential DOM methods in JavaScript for selecting HTML elements using CSS selectors. `querySelector()` returns the first matching element, while `querySelectorAll()` returns all matching elements as a static `NodeList`. These methods simplify DOM manipulation, making it easy to read, update, or modify elements dynamically. In **Lightning Web Components (LWC)**, similar functionality is achieved using `this.template.querySelector()` and `this.template.querySelectorAll()`, ensuring that DOM access is limited to the component's template and follows Shadow DOM principles.
