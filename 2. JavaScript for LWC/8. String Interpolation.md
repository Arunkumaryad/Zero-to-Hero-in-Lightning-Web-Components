# String Interpolation

> **String Interpolation** is an ES6 feature in JavaScript that allows you to **embed variables and expressions directly inside a string** using **template literals** (backticks `` ` ``). It makes string creation easier, cleaner, and more readable than traditional string concatenation.

---

# 📖 Overview

Before ES6, developers used the **`+` operator** to combine strings and variables.

### Without String Interpolation

```javascript
var name = "Arun";

console.log("My name is " + name);
```

Output

```
My name is Arun
```

With ES6, JavaScript introduced **Template Literals**, making this process much simpler.

### With String Interpolation

```javascript
var name = "Arun";

console.log(`My name is ${name}`);
```

Output

```
My name is Arun
```

# What is String Interpolation?

String Interpolation is a JavaScript feature that allows you to insert **variables**, **expressions**, or **JavaScript code** directly inside a string without using the `+` operator.

It uses:

- Backticks `` ` ``
- Placeholder syntax `${}`

---

# What are Template Literals?

Template Literals are strings enclosed using **backticks** instead of single (`'`) or double (`"`) quotes.

### Syntax

```javascript
`Your text here`
```

Variables and expressions are written inside:

```javascript
${ }
```

Example

```javascript
let name = "Arun";

console.log(`Hello ${name}`);
```

Output

```
Hello Arun
```

---

# Why Use String Interpolation?

Without Template Literals

```javascript
let name = "Arun";

console.log("Hello " + name);
```

With Template Literals

```javascript
let name = "Arun";

console.log(`Hello ${name}`);
```

The second approach is much cleaner and easier to read.

---

# 1. String Interpolation Using Variables

### Example

```javascript
var name = "Arun";

console.log(`My name is ${name}`);
```

Output

```
My name is Arun
```

### Explanation

- `name` is a JavaScript variable.
- `${name}` inserts its value into the string.
- No concatenation (`+`) is required.

---

# 2. String Interpolation with Expressions

One of the biggest advantages of template literals is that you can evaluate JavaScript expressions directly inside `${}`.

### Example

```javascript
var a = 10;

var b = 20;

console.log(`Sum of ${a} and ${b} is ${a + b}`);
```

Output

```
Sum of 10 and 20 is 30
```

### Explanation

Inside `${}` JavaScript evaluates:

```javascript
a + b
```

The result (`30`) is inserted into the string automatically.

---

# Variables vs Expressions

### Variable

```javascript
let name = "Salesforce";

console.log(`Hello ${name}`);
```

Output

```
Hello Salesforce
```

---

### Expression

```javascript
let x = 5;

let y = 10;

console.log(`${x} + ${y} = ${x + y}`);
```

Output

```
5 + 10 = 15
```

Expressions are evaluated before being inserted into the string.

---

# Traditional Concatenation vs String Interpolation

### Traditional Method

```javascript
let firstName = "Arun";

let age = 24;

console.log("Name: " + firstName + ", Age: " + age);
```

Output

```
Name: Arun, Age: 24
```

---

### Modern Method

```javascript
let firstName = "Arun";

let age = 24;

console.log(`Name: ${firstName}, Age: ${age}`);
```

Output

```
Name: Arun, Age: 24
```

The template literal version is more readable and easier to maintain.

---

# Multiple Variables Example

```javascript
let firstName = "Arun";

let lastName = "Yadav";

console.log(`Welcome ${firstName} ${lastName}`);
```

Output

```
Welcome Arun Yadav
```

---

# Using Functions Inside Interpolation

You can even call functions inside `${}`.

```javascript
function greet(name) {

    return `Hello ${name}`;

}

console.log(`${greet("Arun")}`);
```

Output

```
Hello Arun
```

---

# Using Object Properties

```javascript
let employee = {

    name: "Arun",

    role: "Salesforce Developer"

};

console.log(`${employee.name} is a ${employee.role}`);
```

Output

```
Arun is a Salesforce Developer
```

# Common Mistakes

### Mistake 1

Using single quotes instead of backticks.

❌ Wrong

```javascript
console.log('Hello ${name}');
```

Output

```
Hello ${name}
```

The variable is **not** replaced.

---

### Correct

```javascript
console.log(`Hello ${name}`);
```

Output

```
Hello Arun
```

---

### Mistake 2

Forgetting `${}`

❌ Wrong

```javascript
console.log(`Hello name`);
```

Output

```
Hello name
```

---

### Correct

```javascript
console.log(`Hello ${name}`);
```

# String Interpolation in LWC

Template literals are commonly used in Lightning Web Components when building dynamic strings.

Example

```javascript
const firstName = "Arun";

const greeting = `Welcome ${firstName}!`;

console.log(greeting);
```

Output

```
Welcome Arun!
```

This makes it easy to create dynamic messages, labels, URLs, and other strings.

# Summary

**String Interpolation** is a modern JavaScript feature introduced in ES6 that makes creating dynamic strings simple and readable. Instead of using the `+` operator to join strings and variables, template literals allow variables and JavaScript expressions to be embedded directly inside strings using the `${}` syntax. This approach improves code readability, reduces errors, and is widely used in modern JavaScript development, including **Lightning Web Components (LWC)**, where dynamic text generation is a common requirement.
