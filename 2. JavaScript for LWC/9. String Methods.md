# String Methods

> **Strings** are one of the most commonly used data types in JavaScript. JavaScript provides many built-in **String Methods** that allow you to search, modify, extract, compare, and manipulate strings efficiently. These methods return new values and do **not** modify the original string because strings are immutable.

---

# 📖 Overview

Strings are sequences of characters enclosed in:

- Single Quotes (`' '`)
- Double Quotes (`" "`)
- Backticks (`` ` ``, Template Literals)

JavaScript provides several built-in methods to perform operations on strings.

# 1. includes()

### Definition

The `includes()` method checks whether a string contains a specified value.

It returns:

- `true` → if found
- `false` → if not found

### Syntax

```javascript
string.includes(searchValue)
```

### Example

```javascript
let str = "Hello i hope you are doing well.";

let checked = str.includes("hope");

console.log(checked);
```

Output

```
true
```

### Explanation

Since the word **"hope"** exists inside the string, JavaScript returns `true`.

---

### Another Example

```javascript
console.log(str.includes("Salesforce"));
```

Output

```
false
```

---

# 2. indexOf()

### Definition

The `indexOf()` method returns the **position (index)** of the first occurrence of a specified text.

If the text is not found, it returns **-1**.

### Syntax

```javascript
string.indexOf(searchValue)
```

### Example

```javascript
let number = str.indexOf("well");

console.log(number);
```

Output

```
27
```

### Explanation

The word **"well"** starts at index **27**.

---

### Example (Not Found)

```javascript
console.log(str.indexOf("Salesforce"));
```

Output

```
-1
```

---

# 3. startsWith()

### Definition

The `startsWith()` method checks whether a string begins with a specified text.

It returns:

- `true`
- `false`

### Syntax

```javascript
string.startsWith(searchValue)
```

### Example

```javascript
console.log(str.startsWith("Hello"));
```

Output

```
true
```

### Explanation

Since the string begins with **Hello**, the result is `true`.

---

### Example

```javascript
console.log(str.startsWith("hope"));
```

Output

```
false
```

---

# 4. slice()

### Definition

The `slice()` method extracts a part of a string and returns it as a new string.

The original string remains unchanged.

### Syntax

```javascript
string.slice(startIndex, endIndex)
```

The ending index is **not included**.

---

### Example

```javascript
let newStr = str.slice(0, 5);

console.log(newStr);
```

Output

```
Hello
```

### Explanation

Characters from index `0` to `4` are extracted.

---

### Example

```javascript
console.log(str.slice(6));
```

Output

```
i hope you are doing well.
```

---

# 5. toLowerCase()

### Definition

The `toLowerCase()` method converts all letters of a string into lowercase.

### Syntax

```javascript
string.toLowerCase()
```

### Example

```javascript
console.log(str.toLowerCase());
```

Output

```
hello i hope you are doing well.
```

### Explanation

Every uppercase letter becomes lowercase.

---

# 6. toUpperCase()

### Definition

The `toUpperCase()` method converts all letters of a string into uppercase.

### Syntax

```javascript
string.toUpperCase()
```

### Example

```javascript
console.log(str.toUpperCase());
```

Output

```
HELLO I HOPE YOU ARE DOING WELL.
```

### Explanation

Every lowercase letter becomes uppercase.

---

# 7. trim()

### Definition

The `trim()` method removes whitespace from both the beginning and the end of a string.

It does **not** remove spaces between words.

### Syntax

```javascript
string.trim()
```

### Example

```javascript
let str2 = "      salesforce LWC      ";

console.log(str2);

console.log(str2.trim());
```

Output

```
      salesforce LWC

salesforce LWC
```

### Explanation

Leading and trailing spaces are removed.

# Summary of String Methods

| Method | Purpose | Return Type |
|---------|----------|------------|
| `includes()` | Checks if text exists | Boolean |
| `indexOf()` | Returns index of first occurrence | Number |
| `startsWith()` | Checks starting text | Boolean |
| `slice()` | Extracts part of string | String |
| `toLowerCase()` | Converts to lowercase | String |
| `toUpperCase()` | Converts to uppercase | String |
| `trim()` | Removes spaces from start and end | String |

---

# Important Notes

### Strings are Immutable

String methods do **not** change the original string.

Example

```javascript
let str = "Hello";

str.toUpperCase();

console.log(str);
```

Output

```
Hello
```

To save the modified value:

```javascript
str = str.toUpperCase();
```

# Best Practices

✅ Use `includes()` instead of complex conditions when checking text.

✅ Use `trim()` before validating user input.

✅ Convert emails to lowercase using `toLowerCase()`.

✅ Store returned values because string methods do not modify the original string.

---

# Common Mistakes

### Mistake 1

Expecting `toUpperCase()` to modify the original string.

❌ Wrong

```javascript
str.toUpperCase();

console.log(str);
```

Output

```
Original string
```

---

### Correct

```javascript
str = str.toUpperCase();
```

---

### Mistake 2

Using `indexOf()` as a Boolean.

❌ Wrong

```javascript
if(str.indexOf("Hello"))
```

Because if the result is `0`, JavaScript treats it as **false**.

---

### Correct

```javascript
if(str.indexOf("Hello") !== -1)
```

or simply

```javascript
if(str.includes("Hello"))
```

---

### Mistake 3

Expecting `trim()` to remove spaces between words.

```javascript
"Hello   World".trim();
```

Output

```
Hello   World
```

Only leading and trailing spaces are removed.

# Key Takeaways

- JavaScript provides many built-in methods for working with strings.
- `includes()` checks whether a value exists in a string.
- `indexOf()` returns the position of a value or `-1` if not found.
- `startsWith()` checks the beginning of a string.
- `slice()` extracts a portion of a string without modifying the original.
- `toLowerCase()` converts all characters to lowercase.
- `toUpperCase()` converts all characters to uppercase.
- `trim()` removes whitespace from the beginning and end of a string.
- String methods return new values because strings are immutable.
