# Events

> **Events** are actions or occurrences that happen in the browser, such as clicking a button, typing in an input field, submitting a form, or moving the mouse. JavaScript allows us to detect these actions and execute specific code in response.

Events are one of the most important concepts in **JavaScript** and **Lightning Web Components (LWC)** because they enable interaction between users and web applications.

---

# 📖 Overview

Web pages become interactive through **events**. Whenever a user performs an action, the browser generates an event. JavaScript listens for these events and executes an **event handler**.

Examples of user actions include:

- Clicking a button
- Typing in a textbox
- Hovering over an element
- Pressing a keyboard key
- Submitting a form

# Event Handler

An **Event Handler** is a JavaScript function that executes whenever an event occurs.

Example

```javascript
function showMessage() {
    alert("Button Clicked");
}
```

# Two Common Ways to Add Events

According to the video, there are two common ways to register events.

---

# 1. HTML Event Handler Attribute

When we add an event directly inside an HTML element, it is called an **HTML Event Handler Attribute**.

**Events always begin with the `on` keyword**, such as:

- onclick
- onchange
- onkeyup

### Example

```html
<button onclick="showMessage()">
    Click Me
</button>
```

```javascript
function showMessage() {
    alert("Hello");
}
```

---

# 2. Event Listener

Event Handlers provide two main methods for dealing with registering and deregistering event listeners.

- `addEventListener()` – register an event handler
- `removeEventListener()` – remove an event handler

---

## addEventListener()

### Syntax

```javascript
element.addEventListener(event, function);
```

### Example

```javascript
const button = document.querySelector("button");

button.addEventListener("click", function () {
    alert("Button Clicked");
});
```

---

## removeEventListener()

This method removes an event listener that was previously added.

### Example

```javascript
function greet() {
    alert("Hello");
}

button.addEventListener("click", greet);

button.removeEventListener("click", greet);
```

# Event Propagation

## Definition

**Event Propagation** explains the order in which events are received on the page from the element where the event occurs and propagated through the DOM tree.

There are two main event models:

1. Event Bubbling
2. Event Capturing

---

# Event Bubbling

## Definition

In the **event bubbling model**, an event starts at the **most specific element** and then flows upward toward the least specific element (the document or even the window).

---

### Example Structure

```html
<form>

    <div>

        <p>Click Me</p>

    </div>

</form>
```

When the paragraph is clicked:

```
p

↓

div

↓

form

↓

body

↓

html

↓

document
```

The event travels upward.

---

### Example

```html
<form onclick="alert('Form')">

    <div onclick="alert('Div')">

        <p onclick="alert('Paragraph')">

            Click Me

        </p>

    </div>

</form>
```

When clicking the paragraph:

```
Paragraph

↓

Div

↓

Form
```

The output will be:

```
Paragraph

Div

Form
```

This is called **Event Bubbling**.

---

# Event Capturing

Event Capturing works in the opposite direction.

The event starts from the **outermost element** and travels down to the target element.

Flow

```
Document

↓

HTML

↓

Body

↓

Div

↓

Button
```

---

# Event Bubbling vs Event Capturing

| Event Bubbling | Event Capturing |
|----------------|-----------------|
| Bottom → Top | Top → Bottom |
| Default behavior | Must be enabled explicitly |
| Most commonly used | Less commonly used |

---

# stopPropagation()

Sometimes we do not want an event to continue bubbling.

We can stop propagation using:

```javascript
event.stopPropagation();
```

Example

```javascript
button.addEventListener("click", function(event){

    event.stopPropagation();

});
```

# Custom Events

## Definition (Based on Video)

In JavaScript we can create our own custom event using the **CustomEvent** constructor.

### Syntax

```javascript
new CustomEvent("eventName", {options});
```

---

# dispatchEvent()

`dispatchEvent()` is used to trigger a custom event.

The **detail** property is used to pass data.

Example from the video

```javascript
element.dispatchEvent(

    new CustomEvent("hello", {

        detail: {

            name: "John"

        }

    })

);
```

---

# Complete Custom Event Example

```javascript
const event = new CustomEvent("welcome", {

    detail: {

        name: "Arun"

    }

});

document.dispatchEvent(event);
```

Listening

```javascript
document.addEventListener("welcome", function(event){

    console.log(event.detail.name);

});
```

Output

```
Arun
```

# Best Practices

✅ Use `addEventListener()` instead of inline JavaScript whenever possible.

✅ Remove unnecessary listeners using `removeEventListener()`.

✅ Use `stopPropagation()` only when required.

✅ Use custom events for communication between components.

---

# Common Mistakes

## Mistake 1

Using inline JavaScript everywhere.

❌ Wrong

```html
<button onclick="save()">
```

Prefer JavaScript listeners.

---

## Mistake 2

Forgetting to remove listeners.

This may lead to memory leaks.

---

## Mistake 3

Using the wrong event name.

Example

```javascript
button.addEventListener("onclick", handler);
```

Correct

```javascript
button.addEventListener("click", handler);
```

---

## Mistake 4

Ignoring event propagation.

Clicking a child element may also trigger parent handlers because of bubbling.

# Key Takeaways

- Events allow JavaScript to respond to user interactions.
- An Event Handler is the function that executes when an event occurs.
- Events can be registered using HTML attributes or `addEventListener()`.
- Event Propagation has two models: **Bubbling** and **Capturing**.
- Bubbling is the default event flow in JavaScript.
- `CustomEvent` enables developers to create custom events and pass data using the `detail` property.
- In LWC, events are essential for handling user actions and enabling communication between components.

---

# Summary

Events are the foundation of interactivity in JavaScript. Whenever a user performs an action such as clicking, typing, or submitting a form, the browser generates an event. JavaScript responds to these events through event handlers, which can be registered using HTML attributes or the `addEventListener()` method. Events propagate through the DOM using **Event Bubbling** or **Event Capturing**, and developers can create their own events using the `CustomEvent` constructor. In **Lightning Web Components (LWC)**, events play a vital role in handling user interactions and enabling communication between parent and child components using `dispatchEvent()`.
