# Object-JSON Operations

> **Objects** are one of the most important data structures in JavaScript. They store data as **key-value pairs**. JavaScript also provides a built-in **JSON (JavaScript Object Notation)** object that allows developers to convert objects into strings and convert strings back into objects. These operations are widely used in APIs, Lightning Web Components (LWC), and Salesforce integrations.

# What is an Object?

### Definition

An **Object** is a collection of related data stored as **key-value pairs**.

### Example

```javascript
let employee = {
    name: "Arun",
    age: 23,
    city: "Delhi"
};
```

Here,

- `name`
- `age`
- `city`

are keys, and their corresponding values are:

- Arun
- 23
- Delhi

---

# What is JSON?

### Definition

**JSON (JavaScript Object Notation)** is a lightweight text format used to exchange data between applications.

JSON looks similar to a JavaScript object but follows a strict syntax:

- Keys must be enclosed in double quotes.
- It is stored as a string.

Example

```json
{
   "name":"Salesforce",
   "age":89
}
```

JSON is commonly used in:

- REST APIs
- Salesforce Integrations
- Apex Callouts
- External Services

---

# Object vs JSON

| Object | JSON |
|---------|------|
| JavaScript data structure | Text/String format |
| Keys may not use quotes | Keys use double quotes |
| Used inside JavaScript | Used for data exchange |
| Can contain functions | Cannot contain functions |

# 1. Object.keys()

## Definition

`Object.keys()` returns an array containing **all the property names (keys)** of an object.

### Syntax

```javascript
Object.keys(object)
```

---

### Example

```javascript
console.log(Object.keys(obj));
```

Output

```javascript
["name", "age", "dob"]
```

### Explanation

JavaScript reads all the property names from the object and returns them as an array.

---

### Another Example

```javascript
let student = {
    name: "Arun",
    course: "Salesforce",
    city: "Delhi"
};

console.log(Object.keys(student));
```

Output

```javascript
["name", "course", "city"]
```

---

# 2. Object.values()

## Definition

`Object.values()` returns an array containing **all the values** of an object.

### Syntax

```javascript
Object.values(object)
```

---

### Example

```javascript
console.log(Object.values(obj));
```

Output

```javascript
["Salesforce", 89, "23/10/2024"]
```

### Explanation

Instead of returning property names, it returns only the values.

---

### Another Example

```javascript
let employee = {
    name: "Arun",
    age: 23,
    city: "Delhi"
};

console.log(Object.values(employee));
```

Output

```javascript
["Arun",23,"Delhi"]
```

---

# 3. JSON.stringify()

## Definition

`JSON.stringify()` converts a JavaScript object into a JSON string.

This is one of the most important methods while sending data to an API.

### Syntax

```javascript
JSON.stringify(object)
```

---

### Example

```javascript
let str = JSON.stringify(obj);

console.log(str);
```

Output

```javascript
{"name":"Salesforce","age":89,"dob":"23/10/2024"}
```

### Explanation

The JavaScript object becomes a JSON-formatted string.

Notice:

- Keys are enclosed in double quotes.
- The entire result is a string.

---

### Check the Type

```javascript
let str = JSON.stringify(obj);

console.log(typeof str);
```

Output

```
string
```

---

# Why use JSON.stringify()?

It is mainly used before:

- Sending data to REST APIs
- Saving data in Local Storage
- Sending request bodies
- Apex Callouts
- External Integrations

---

Example

```javascript
const body = JSON.stringify({
    name: "Arun",
    city: "Delhi"
});
```

---

# 4. JSON.parse()

## Definition

`JSON.parse()` converts a JSON string back into a JavaScript object.

### Syntax

```javascript
JSON.parse(jsonString)
```

---

### Example

```javascript
console.log(JSON.parse(str));
```

Output

```javascript
{
   name: "Salesforce",
   age: 89,
   dob: "23/10/2024"
}
```

### Explanation

The JSON string is converted back into a normal JavaScript object.

---

### Check Type

```javascript
let object = JSON.parse(str);

console.log(typeof object);
```

Output

```
object
```

# Complete Example

```javascript
let obj = {
    name: 'Salesforce',
    age: 89,
    dob: '23/10/2024'
};

console.log(obj);

// Object.keys()
console.log(Object.keys(obj));

// Object.values()
console.log(Object.values(obj));

// Convert Object → JSON String
let str = JSON.stringify(obj);

console.log(str);

// Convert JSON String → Object
console.log(JSON.parse(str));
```

Output

```javascript
{
  name: "Salesforce",
  age: 89,
  dob: "23/10/2024"
}

["name","age","dob"]

["Salesforce",89,"23/10/2024"]

{"name":"Salesforce","age":89,"dob":"23/10/2024"}

{
  name:"Salesforce",
  age:89,
  dob:"23/10/2024"
}
```

# Real-World Examples

## Example 1: Get All Object Keys

```javascript
const account = {
    Name: "ABC School",
    City: "Delhi",
    Board: "CBSE"
};

console.log(Object.keys(account));
```

Output

```javascript
["Name","City","Board"]
```

---

## Example 2: Get All Values

```javascript
console.log(Object.values(account));
```

Output

```javascript
["ABC School","Delhi","CBSE"]
```

---

## Example 3: Send Data to API

```javascript
const payload = {
    name: "Arun",
    city: "Delhi"
};

const requestBody = JSON.stringify(payload);

console.log(requestBody);
```

Output

```javascript
{"name":"Arun","city":"Delhi"}
```

---

## Example 4: Receive API Response

```javascript
const response =
'{"success":true,"message":"Record Created"}';

const result = JSON.parse(response);

console.log(result.success);

console.log(result.message);
```

Output

```
true

Record Created
```

# Best Practices

✅ Use `Object.keys()` when you need only property names.

✅ Use `Object.values()` when only values are required.

✅ Convert objects into JSON before sending API requests.

✅ Parse JSON responses before using their data.

# Common Mistakes

## Mistake 1

Trying to access properties from a JSON string.

❌ Wrong

```javascript
let json = JSON.stringify(obj);

console.log(json.name);
```

Output

```
undefined
```

---

### Correct

```javascript
let object = JSON.parse(json);

console.log(object.name);
```

---

## Mistake 2

Using `JSON.parse()` on an object.

❌ Wrong

```javascript
JSON.parse(obj);
```

This throws an error because `JSON.parse()` expects a **string**, not an object.

---

### Correct

```javascript
JSON.stringify(obj);
```

or

```javascript
JSON.parse(jsonString);
```
