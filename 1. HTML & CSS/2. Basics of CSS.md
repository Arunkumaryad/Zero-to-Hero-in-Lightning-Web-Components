# 📖 Overview

CSS (**Cascading Style Sheets**) is a stylesheet language used to describe the appearance and layout of HTML elements.

In Salesforce Lightning Web Components (LWC), CSS is used to style component templates. Each LWC component can have its own CSS file, making component styling modular and reusable.

# CSS Selectors

## Actual Definition (Based on the Video)

> **CSS selectors are used to "find" (or select) the HTML elements you want to style.**

---

# 💡 Simple Definition

Selectors tell CSS which HTML element should receive the style.

---

# Types of CSS Selectors

---

## 1. Element Selector

### Actual Definition

> **Use of HTML tags for styling.**

Example

```css
p {
    color: blue;
}
```

Explanation

Styles every `<p>` tag.

HTML

```html
<p>Hello</p>

<p>Salesforce</p>
```

Output

Both paragraphs become blue.

---

## 2. ID Selector

### Actual Definition

> **Uses the id attribute of an HTML element to select a specific element. To select an element with a specific id, write a hash (#) character, followed by the id of the element. The id of an element should be unique within a page.**

Example

```css
#username {
    color: red;
}
```

HTML

```html
<h1 id="username">
    Arun
</h1>
```

Output

Only this element becomes red.

---

## 3. Class Selector

### Actual Definition

> **Uses the class attribute of an HTML element to select a specific element. To select an element with a specific class, write a dot (.) character, followed by the class of the element.**

Example

```css
.username {
    color: blue;
}
```

HTML

```html
<h2 class="username">
    Salesforce
</h2>
```

Output

Text becomes blue.

---

# Difference Between ID and Class

| ID Selector | Class Selector |
|-------------|----------------|
| Uses `#` | Uses `.` |
| Unique | Can be reused |
| Applied to one element | Applied to multiple elements |
| Example: `#header` | Example: `.header` |

# Types of CSS Styles

## Actual Definition (Based on the Video)

There are **three types of CSS styles**.

1. **Internal CSS – Not used in LWC**
2. **Inline CSS**
3. **External CSS or Third Party Library – Bootstrap, Salesforce Lightning Design System**

---

# 1. Internal CSS

### Simple Definition

Internal CSS is written inside the `<style>` tag within an HTML file.

Example

```html
<style>

h1{
    color:red;
}

</style>
```

### In LWC

❌ Not used in Lightning Web Components.

---

# 2. Inline CSS

### Simple Definition

CSS is written directly inside an HTML element using the `style` attribute.

Example

```html
<h1 style="color:red;">
    Salesforce
</h1>
```

### LWC Example

```html
<div style="color:green;">
    Hello World
</div>
```

---

# 3. External CSS

### Simple Definition

CSS is written in a separate `.css` file and linked to the HTML.

In LWC

```
component.html

component.js

component.css
```

Example

component.css

```css
.title {

    color: blue;

    font-size: 24px;

}
```

component.html

```html
<h1 class="title">

    Salesforce

</h1>
```

---

# Third-Party CSS Libraries

Example

<div class="slds-box">

</div>

# CSS Box Model

## Actual Definition (Based on the Video)

> **It is a box that wraps around every HTML element.**

---

# 💡 Simple Definition

Every HTML element behaves like a rectangular box.

The box consists of four parts.

```
Margin

↓

Border

↓

Padding

↓

Content
```

---

# Parts of the Box Model

## 1. Content

The actual text, image, or data inside the element.

Example

```
Hello World
```

---

## 2. Padding

Space between content and border.

Example

```css
padding:20px;
```

---

## 3. Border

Line around the padding.

Example

```css
border:2px solid black;
```

---

## 4. Margin

Space outside the border.

Example

```css
margin:30px;
```

---

# Visual Representation

```
-------------------------

Margin

-------------------------

Border

-------------------------

Padding

-------------------------

-------------------------
```

---

# Complete Box Model Example

HTML

```html
<div class="box">

    Salesforce

</div>
```

CSS

```css
.box {

    margin:20px;

    border:2px solid black;

    padding:25px;

    background:lightblue;

}
```

# CSS in Lightning Web Components

Each Lightning Web Component can have its own CSS file.

Structure

```
myComponent

│

├── myComponent.html

├── myComponent.js

├── myComponent.css

└── myComponent.js-meta.xml
```

Example

### HTML

```html
<template>

    <h1 class="title">

        Hello Salesforce

    </h1>

</template>
```

---

### CSS

```css
.title {

    color: blue;

    font-size: 28px;

    text-align: center;

}
```

CSS helps you:

# Best Practices

✅ Use meaningful class names.

✅ Keep CSS in the component's `.css` file.

✅ Prefer classes instead of inline styles.

✅ Use SLDS whenever possible in Salesforce.

✅ Avoid unnecessary IDs.

✅ Write clean and readable CSS.

---

# Common Mistakes

❌ Forgetting the selector.

❌ Missing semicolons.

❌ Using IDs everywhere instead of classes.

❌ Using too much inline CSS.

❌ Ignoring the CSS Box Model.

# Key Takeaways

- CSS stands for Cascading Style Sheets.
- CSS controls the appearance of HTML elements.
- CSS syntax follows the format: `selector { property: value; }`.
- Selectors are used to target HTML elements for styling.
- The most common selectors are Element, ID, and Class selectors.
- LWC primarily uses External CSS through component-specific `.css` files.
- Internal CSS is not used in LWC.
- The CSS Box Model consists of Content, Padding, Border, and Margin.
- Salesforce developers should prefer SLDS for consistent and responsive UI design.
