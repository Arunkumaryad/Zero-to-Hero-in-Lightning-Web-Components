# Basics of HTML

> Learn the fundamentals of HTML, including commonly used HTML elements, attributes, custom data attributes, and the difference between block-level and inline elements. These concepts are essential for building Lightning Web Components (LWC) because every LWC template is written using HTML.

---

# 📖 Overview

HTML (**HyperText Markup Language**) is the standard markup language used to create the structure of web pages.

In Salesforce Lightning Web Components (LWC), every component contains an HTML file that defines what will be displayed on the user interface.

Understanding HTML is the first step toward becoming an LWC developer.

# 📖 Actual Definition (Based on the Video)

## HTML Element

> **An HTML element is defined by a start tag, some content, and an end tag.**

Example

```html
<h1>My First Heading</h1>
```

Here,

- `<h1>` → Start Tag
- `My First Heading` → Content
- `</h1>` → End Tag

---

# 💡 Simple Definition

An HTML element is a building block of a webpage.

It consists of:

- Opening Tag
- Content
- Closing Tag

Example

```html
<p>Hello World</p>
```

---

# Structure of an HTML Element

```
<opening-tag>

      Content

</closing-tag>
```

Example

```
<h1>

Salesforce

</h1>
```

# Most Commonly Used HTML Elements

---

## 1. `<div>`

### Actual Definition

> **This tag defines a division in an HTML document.**

### Simple Definition

A `<div>` is used to divide a webpage into different sections.

Example

```html
<div>
    Welcome to Salesforce
</div>
```

Output

```
Welcome to Salesforce
```

---

## 2. `<p>`

### Actual Definition

> **This tag is used for paragraphs that start on a new line and add some margin before and after a paragraph.**

### Simple Definition

The `<p>` tag is used to display paragraph text.

Example

```html
<p>This is my first paragraph.</p>
```

Output

```
This is my first paragraph.
```

---

## 3. `<h1>` to `<h6>`

### Actual Definition

> **These tags are used to give headings of different sizes.**

### Simple Definition

Heading tags display titles.

`<h1>` is the largest heading.

`<h6>` is the smallest heading.

Example

```html
<h1>Main Heading</h1>

<h2>Sub Heading</h2>

<h3>Small Heading</h3>
```

---

## 4. `<a>`

### Actual Definition

> **This tag defines a hyperlink.**

### Simple Definition

The `<a>` tag is used to create clickable links.

Example

```html
<a href="https://google.com">
    Google
</a>
```

Output

Clicking the text opens Google.

---

## 5. `<img>`

### Actual Definition

> **This tag helps you insert an image into a web page.**

### Simple Definition

The `<img>` tag displays an image.

Example

```html
<img src="logo.png">
```

---

## 6. `<ul>`

### Actual Definition

> **This will list items using plain bullets.**

### Simple Definition

The `<ul>` tag creates an unordered (bulleted) list.

Example

```html
<ul>

    <li>Apple</li>

    <li>Mango</li>

    <li>Orange</li>

</ul>
```

Output

```
• Apple

• Mango

• Orange
```

# HTML Attributes

## Actual Definition

- **HTML attributes provide additional information about HTML elements.**
- **Attributes are always specified in the start tags.**
- **Attributes usually come in name/value pairs like: name="value".**

---

# 💡 Simple Definition

Attributes add extra information or behavior to an HTML element.

Syntax

```html
attribute="value"
```

Example

```html
<a href="https://google.com">
    Google
</a>
```

Here

```
href
```

is the attribute.

```
https://google.com
```

is the attribute value.

---

# Common HTML Attributes

| Attribute | Purpose |
|------------|----------|
| id | Unique identifier |
| class | Apply CSS styles |
| href | Hyperlink URL |
| src | Image source |
| alt | Alternative image text |
| title | Tooltip text |
| style | Inline CSS |
| disabled | Disable an element |

---

# HTML data-* Attribute

## Actual Definition

> **The data-* attribute is used to store custom data private to the page or application.**

Example

```html
<div data-name="nikhil">

    Username

</div>
```

---

# 💡 Simple Definition

The `data-*` attribute stores custom information inside an HTML element.

This data is not visible on the webpage but can be accessed using JavaScript.

Example

```html
<button data-id="100">

    Save

</button>
```

JavaScript

```javascript
event.target.dataset.id
```

Output

```
100
```

---

# Why is data-* Important in LWC?

The `data-*` attribute is widely used in Lightning Web Components.

Example

```html
<lightning-button

    label="Delete"

    data-id={account.Id}

    onclick={handleDelete}

></lightning-button>
```

JavaScript

```javascript
handleDelete(event) {

    let accountId = event.target.dataset.id;

}
```

# HTML Block and Inline Elements

HTML elements are divided into two categories:

- Block-Level Elements
- Inline Elements

---

# Block-Level Elements

## Actual Definition

> **Block-level elements always start on a new line and take up the full width available.**

Examples

```
<div>

<p>

<h1> - <h6>

<ul>

<header>

<article>
```

---

# 💡 Simple Definition

A block element always starts from a new line.

It occupies the entire width available.

Example

```html
<div>First</div>

<div>Second</div>
```

Output

```
First

Second
```

Each element appears on a separate line.

---

# Inline Elements

## Actual Definition

> **Inline elements do not start on a new line and only take up as much width as necessary.**

Examples

```
<span>

<img>

<a>

<label>

<strong>
```

---

# 💡 Simple Definition

Inline elements stay in the same line unless there is no space.

Example

```html
<span>Hello</span>

<span>World</span>
```

Output

```
Hello World
```

---

# Block vs Inline Elements

| Block-Level Elements | Inline Elements |
|----------------------|-----------------|
| Start on a new line | Stay on the same line |
| Occupy full width | Occupy only required width |
| Used for page structure | Used for formatting content |
| Can contain block and inline elements | Usually contain text or inline elements |

# HTML in Lightning Web Components

Every LWC contains an HTML template.

Example

```html
<template>

    <div>

        <h1>Welcome</h1>

        <p>Hello Salesforce</p>

        <a href="https://salesforce.com">
            Visit Salesforce
        </a>

    </div>

</template>
```

# Best Practices

✅ Use semantic HTML whenever possible.

✅ Use heading tags in proper order (`<h1>` → `<h6>`).

✅ Use `<div>` for grouping related content.

✅ Use meaningful attributes.

✅ Use `data-*` attributes to pass custom data to JavaScript.

✅ Keep HTML clean and properly indented.

---

# Common Mistakes

❌ Forgetting the closing tag.

❌ Using block elements where inline elements are sufficient.

❌ Hardcoding styles instead of using CSS files.

❌ Using too many nested `<div>` elements unnecessarily.

❌ Forgetting to use `data-*` when passing custom values to event handlers.

# Interview Questions

### 1. What is HTML?

HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages.

---

### 2. What is an HTML Element?

An HTML element is defined by a start tag, some content, and an end tag.

---

### 3. What is the purpose of the `<div>` tag?

It defines a division or section in an HTML document.

---

### 4. What are HTML Attributes?

Attributes provide additional information about HTML elements and are specified in the start tag.

---

### 5. What is the `data-*` attribute?

It is used to store custom data private to the page or application, which can be accessed using JavaScript.

---

### 6. What is the difference between Block-Level and Inline Elements?

Block-level elements start on a new line and take up the full width, while inline elements remain on the same line and only take up as much width as needed.

---

### 7. Why is the `data-*` attribute important in LWC?

It allows developers to pass custom values (such as record IDs) from HTML to JavaScript event handlers without displaying them in the UI.

# Key Takeaways

- HTML is the foundation of every Lightning Web Component.
- An HTML element consists of a start tag, content, and an end tag.
- Common HTML elements include `<div>`, `<p>`, `<h1>`–`<h6>`, `<a>`, `<img>`, and `<ul>`.
- Attributes provide additional information to HTML elements.
- The `data-*` attribute is commonly used in LWC to store custom values that JavaScript can access.
- Block-level elements start on a new line, while inline elements stay on the same line.
- Understanding these HTML basics is essential before learning advanced LWC concepts.
